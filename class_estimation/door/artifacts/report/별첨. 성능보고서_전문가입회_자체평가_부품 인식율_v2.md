## 7. 시험 방법 및 조건

### 7.1 평가 방법

- 1단계-1차년도 자체평가
- 부품 인식 시스템의 평가지표로 **인식율(Accuracy)** 을 사용하며, 혼동 행렬(Confusion Matrix)을 기반으로 평가함

$$
\text{인식율} = \frac{\sum_{i=1}^{k} \text{Correct}_i}{\text{Total Samples}} = \frac{\text{올바르게 예측된 샘플 총합}}{\text{전체 테스트 샘플 수}}
$$

- **통계적 신뢰성 확보를 위해 서로 다른 5개의 랜덤 시드(seed)로 동일 실험을 반복** 하여 평균(mean) ± 표준편차(std)를 산출함
  - 사용 시드: [42, 123, 456, 789, 1024]
  - 각 시드마다 데이터 분할(Train/Test)과 모델 초기화가 독립적으로 수행됨
  - 단일 시드 결과만으로는 데이터 분할 및 가중치 초기화의 확률적 변동을 반영할 수 없으므로, 복수 시드 반복 실험을 통해 성능의 안정성과 재현성을 정량적으로 검증함

| 학습/테스트 비율 | 70:30 | 70:30 (Stratified split) |

| 운영 체제 | Windows, Linux 또는 macOS | Ubuntu 24.04 LTS |
| 프레임워크 | TensorFlow or PyTorch | PyTorch 2.11.0 + cu130 |
| 라이브러리 | scikit-learn | scikit-learn 1.8.0 |
| 개발도구 | VS Code (IDE) | VS Code (IDE) |

> *1단계 1차년도에는 웹상의 데이터셋으로 자체 개발 및 평가를 수행 예정이었으나, 실물 데이터를 확보하여 실물 데이터 기반으로 평가를 수행함.*

### 7.3 데이터셋 구축 및 분할

굴착기 3개 모델(E25, E30, E38)의 도어 3종(door_RH, door_LH_FRT, door_LH_RR)을 조합하여 총 8개 클래스를 구성함.

| 구분 | 이미지 수 | 클래스 수 | 비율 | 비고 |
|------|:---------:|:---------:|:----:|------|
| 전체 데이터 | 1,256장 | 8 | 100% | RGBD 4채널 |
| 학습 데이터 (Train) | 879장 | 8 | 70% | Stratified split |
| 테스트 데이터 (Test) | 377장 | 8 | 30% | Stratified split |

### 7.4 AI 모델 학습

| 항목 | 내용 |
|------|------|
| 기반 모델 | ResNet18 (ImageNet 사전학습 가중치 활용, 전이학습) |
| 입력 | RGBD 4채널 (conv1 레이어 수정, Depth 채널 추가) |
| 보조 분류기 | Auxiliary Head (중간 특징맵 기반 보조 손실) |
| Optimizer | Adam (lr=0.001) |
| Batch Size | 64 |
| 최대 에폭 | 60 |
| 조기 종료 | Early Stopping (patience=10) |
| 전처리 | Letterbox 리사이징 (448×448), ImageNet 정규화, Depth 클리핑 (5m) |

### 9.2 결과 분석

굴착기 부품 인식 AI 모델(RGBDAuxResNet18)의 혼동 행렬 기반 인식율 시험을 완료함.

1. **원본 테스트 성능**: 5회 반복 실험에서 평균 99.52%의 인식율을 달성하였으며, 표준편차 0.81%로 매우 안정적인 성능을 보임. 5개 seed 중 3개(seed 42, 123, 1024)에서 100%를 달성하였고, 가장 낮은 경우(seed 456)에서도 98.14%로 높은 수준을 유지함.

2. **텍스처 변형 증강 성능**: 전경 증강(증강1) 평균 90.13%, 전체 증강(증강2) 평균 91.88%로, 원본 대비 약 8~10%의 성능 하락이 관찰됨. 이는 모델이 RGB 텍스처 패턴에 일부 의존하고 있음을 시사함.

3. **Seed간 변동성 분석**: 증강 데이터에서 seed간 표준편차가 2~3%로 나타나, 데이터 분할에 따른 성능 변동이 존재함. 특히 seed 1024의 전체 증강 결과(86.21%)가 다른 seed 대비 낮은 값을 보였으며, 이는 단일 seed만으로 평가할 경우 성능을 과소 또는 과대 추정할 수 있음을 보여줌.

4. **클래스별 분석**: 증강 조건에서 E30_door_LH_FRT 클래스가 F1 81.37 ± 6.63%(전경 증강)으로 가장 낮은 성능을 보임. 이는 E30과 E38의 LH_FRT 도어 간 형상 유사성이 높아, 텍스처 정보가 변형되면 구별이 어려워지는 것으로 분석됨.

### 9.3 결론

- 1차년도 목표(70%) 대비 **99.52%** 를 달성하여 목표를 초과 달성함.
- 5-seed 반복 실험을 통해 단일 실험의 확률적 변동을 배제하고 통계적으로 신뢰할 수 있는 성능을 확인함.
- 다만 이는 **통제된 환경에서 촬영한 소규모 데이터셋(8클래스, 1,256장)** 에 대한 결과이며, 텍스처 변형 증강 시 약 **90%** 수준으로 하락하는 점에서 **실환경 적용 시 성능 저하 가능성**이 확인됨.
- 차년도에는 부품 종류 확대, 실환경 데이터 확보, 텍스처 의존성 저감(Depth/Edge 채널 활용) 등을 통해 **실환경 조건에서도 99% 이상의 최종목표 달성**을 추진할 예정.
