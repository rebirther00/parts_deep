# datasets_factory — 현장 취득 데이터 (ZED 2i)

## 라벨링 이력

현장 데이터 수집 시(2026-04) 대차 세션 55장(`rgb/depth_0012~0066`)이
`E25_door_LH_RR` 폴더에 잘못 저장되는 라벨링 실수가 있었음.

- **2026-07-06**: 사용자 확인으로 #0012~0066을 `E25_door_RH`로 이동 (1차 정정).
- **2026-07-07**: 슬롯 개수(24×2) 및 종횡비 확인 결과 실제 부품은
  **E30_E38_door_RH**로 재확정 → `E30_E38_door_RH/`로 최종 이동 (2차 정정).
  속성 파이프라인의 예측(E30_E38_door_RH) 및 실측 종횡비(1.067,
  E30_E38 중심 1.059)와도 일치.

최종 구성:
- `E25_door_LH_RR/`: #0000~0011 (지그 세션, 12장) — 진짜 E25_door_LH_RR
- `E30_E38_door_RH/`: #0000~0010 (기존 11장) + #0012~0066 (대차 세션 55장) = 66장
- `E25_door_RH/`: 비어 있음 (현장 데이터 미취득)

주의: 라벨 정정 이전에 산출된 현장 평가 결과(14.1% 등)는 오염된 ground truth
기준이므로 인용하지 말 것. 재평가는 `door_paper/evaluate_factory.py`.

참고 — CAD 기준 슬롯 개수: E25_RH 40개(≈19~20×2), E30_E38_RH 50개(≈24~25×2).
슬롯 개수와 종횡비(E25_RH 1140×990, E30_E38_RH 1191×1140)가 현장 육안
검증 기준으로 유효.
