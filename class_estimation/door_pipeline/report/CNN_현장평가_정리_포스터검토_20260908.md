# RGBE CNN(1차년도 실험실 알고리즘) 현장 데이터 적용 정리 및 학회 포스터 가능성 검토

작성 2026-09-08. 근거 데이터: `report/hole_analysis/field_20260907/`, DB `db/door_pipeline.db`(training_sessions #8~#10).

## 1. 알고리즘 (변경 없음)

1차년도 실험실에서 확정한 **RGBE NoAux 448** 그대로. ResNet18(ImageNet 초기화) 백본, 입력 4채널 = RGB + Canny 엣지(80/200),
conv1을 4채널로 확장(엣지 채널 가중치 = RGB 평균), 헤드 Dropout→512→256→클래스. 전체 프레임 448 레터박스,
Adam 1e-3, 역빈도 클래스 가중 CE, val 정확도 조기 종료(patience 10). 파라미터 11.3M. 현장 적용에서 바꾼 것은 **데이터와 분할 방식뿐**이다.

## 3. 결과

| 실험 | test | 결과 |
|---|---|---|
| 실험실 모델(seed42) → 실험실 test | 189장 | 100% |
| 실험실 모델 → 현장 test(세션 격리) | 384장 | **22.9%** (6종 0%, E30_E38_RH로 쏠림) |
| 현장 학습(정식 run #10, seed42) → 현장 test | 348장 | **91.4%** (8종 100%, E30_LH_RR 8/27 한 세션 0/30) |
| 현장 5-fold 세션 그룹 CV (8/10 제외) | 77세션 1,663장 | **97.4%** (fold 91.8~100, 72/77 세션 100%) |
| 참고: 홀 랜드마크 판별기(기하 기반, 주 판별기) | 9종 1,699장 | 판정 98%, 판정 정확도 99.9% |

해석: 동일 알고리즘이 실험실→현장 도메인 이동에서 붕괴(22.9%)했고, 현장 데이터로 재학습하면 세션 격리 기준 97%대로 회복한다.
남은 오류는 촬영 프로토콜 정착 전 세션(도어 위치 편차·작업자/장비 프레임 침입)과 크기 인접 쌍(E30↔E38)에 집중된다.

## 5. 이 CNN만으로 학회 포스터 발표가 가능한가 (1차 검토 — 6절에서 방향 수정)

**가능하되, "새 알고리즘"이 아니라 "실험실→현장 도메인 이동 사례 연구"로 프레이밍해야 한다.** 판단 근거:

강점(포스터 거리)
- 같은 모델이 실험실 100% → 현장 22.9% → 현장 재학습 97.4%라는 명확한 스토리.
- 세션 단위 분할·세션 그룹 CV라는 평가 프로토콜(연속 프레임 누출 방지)은 현장 데이터 논문에서 자주 빠지는 부분이라 그 자체가 기여점.
- 실패 사례 분석(프로토콜 이전 세션, 인접 크기 쌍)이 이미지와 함께 있음.
- 9종·84세션·8,000쌍의 실제 생산 현장 데이터.

약점(심사 지적 예상)
- ResNet18+엣지 채널은 방법론 신규성이 없음 → 방법 논문으로는 불가, 응용·사례 포스터로만 가능.
- 엣지 채널의 현장 효과가 미검증(RGB-only 대조 없음). 4채널을 주장하려면 4번 실험 필수.
- 단일 시드, 단일 현장, 9종 중 1종(E25_LH_FRT) 미평가.
- 같은 데이터에서 기하 기반 홀 판별기가 99.9%라, "왜 CNN인가"에 답이 필요. 답은 (a) CAD 없이 학습만으로 동작, (b) 홀이 가려지거나 프레임 밖일 때의 폴백, (c) 신규 부품(E23) 대응에 CAD 등록이 필요 없는 점.

권고: 4·5번 실험(약 12~15시간 GPU)을 추가한 뒤 국내 학회 포스터(응용 세션)로 내는 것은 무리가 없다.
제목 방향 예: "실험실 학습 도어 분류 CNN의 생산 현장 적용: 세션 단위 평가와 현장 재학습 효과".
홀 판별기와 묶어 "외관 기반 CNN vs 기하 기반 판별기 비교"로 내면 기여점이 더 뚜렷해진다.

## 6. 포스터 방향 확정 (2026-09-08, 2차 검토)

### 6.1 프레이밍
- **채택: "굴착기 도어 용접 공정 자동화를 위한 현장 데이터 수집·검증 체계 구축 사례"** — 현재 수동 공정(작업자가 부품 클래스를 지정)에서
  향후 자동 공정(비전 판별·로봇 연계)에 쓸 데이터를 확보하고, 그 데이터가 쓸모 있음을 판별기로 입증.
- 실험실 CNN의 현장 22.9%는 **넣지 않는다**(환경 차이로 예견된 실패, 기여점 아님).
- 데이터 활용 증거의 주역은 **기하 기반 홀 판별기**: 실험실 이미지 118장 + 첫 방문 현장 16장에 6점씩 찍은 **간단한 라벨(134장)** 만으로 학습해,
  현장 9종 1,699장에서 **추가 현장 홀 라벨링 없이** 판정 정확도 99.9%. 신규 부품(E23)도 CAD 치수 한 줄로 즉시 판정. CNN 97.4%는 보조 증거.

### 6.2 패널별 근거 점검 (정말 구성 가능한가)

| 패널 | 주장 | 근거(이미 있는 것) | 빈 곳·주의 |
|---|---|---|---|
| 1 배경·목표 | 수동→자동 공정, 자동화 전 필요 요건 3가지(현장 데이터·라벨 신뢰·평가 기준) | 9/3 현장 점검 자료(R1), 실태조사 v2 | 자동 공정 목표 그림은 개념도로(로봇 연계 미착수) |
| 2 수집 체계 | ZED X Mini + ZED Box 캡처 UI → NAS → DB → 웹 | `06_factory_capture.py`, `db/` 스키마·webapp, 84세션 ~8,000쌍(8/27~9/5) | 시스템 구성도 신규 작성 필요. 세션당 20장 샘플 정책 설명 |
| 3 데이터 품질 관리 | 기하 판별기 D로 세션 단위 자동 플래그 → 육안 확정 | 정정 7세션(오선택 3, 미등록 E23 4), 대조 시트 `cmp1/cmp2`, DB notes 이력 | 현장 사진 공개 동의 필요 |
| 4 평가 프로토콜 | 세션 단위 분할·세션 그룹 CV | `build_dataset.py auto-split`, `session_cv.py`, 프레임 vs 세션 분할 차이 | 프레임 단위 분할 시 수치 부풀림을 보여줄 대조 실험은 **없음** — 개념 설명으로 대체하거나 1회 실험(40분) 추가 |
| 5 데이터 활용 검증 | 홀 판별기 99.9%(134장 라벨), CNN CV 97.4%, 실패 세션 = 촬영 조건 → 프로토콜 반영 | `eval_classifier_datasets_factory_v2_all.json`, `cnn_cv5_results.json`, `fail1` 시트 | 홀 판별기는 depth·코너 홀 가시성 필요(보류 2%) 한계 명기 |
| 6 로드맵 | 엣지 자동 판정, 6DoF 자세 연계, 트래커 검증, 로봇 연계 | 자세 추정 현장 정합 잔차 med 3.3~4.9mm(`pos_pipeline`), 트래커 프로토콜 문서 | 전부 "계획"으로 표기. 실측 없음 |

결론: 6개 패널 중 5개는 지금 있는 산출물로 채워지고, 4번 패널의 대조 실험 하나가 선택 사항이다. **구성 가능**.
약점은 단일 현장·단일 카메라·9종·2주 수집이라는 규모이며, "구축 사례"로 쓰면 이는 한계 절에 적으면 된다.

### 6.3 학회 적합성
- **한국자동차공학회 어스무빙머시너리 부문**: 부품이 굴착기 도어이고 청중이 건설기계 설계·생산 엔지니어라 사례 발표로 적합.
  스마트 제조·자동화 관련 세션이 있으면 그쪽, 없으면 생산기술 일반 세션. **1순위**.
- **유공압건설기계학회**: 건설기계 범주로 가능하나 유공압 중심 청중이라 제조 데이터 주제는 주변부. 2순위.
- 그 외: 한국정밀공학회·한국생산제조학회 스마트팩토리 세션이 주제 적합성은 더 높지만, 연구원 참여 학회를 우선하면 위 둘로 충분.
- 결정 요소: 제출 마감(초록 분량·포스터 규격)과 현장 사진 공개 동의 시점. 마감이 가까우면 4번 패널 대조 실험은 생략.
