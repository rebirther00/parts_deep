## 1. 데이터 종류 및 확보

**1-1. 필요한 제조 데이터 정의**
도어 8종(차종 E25/E30/E38 × 위치 앞문/뒷문/우측, E30·E38 우측은 동일 부품)을 자동 인식하기 위해 **RGB 이미지 + 깊이(Depth) 이미지 쌍**을 표준 데이터로 정의. 해상도 1920×1200, 깊이는 mm 단위 16비트. 각 도어 종류의 판별 기준(외형 치수, 통풍구 슬롯 수·배치)을 설계 CAD에서 추출해 스펙 파일로 관리하며, 이 스펙은 AI 판정 시 직접 사용됨.

**1-2. 실라인 데이터 스펙**
현장(경주 공장) 수집 장비·주기·통신을 운영 문서로 정의하여 가동 중.
- 장비: 스테레오 깊이 카메라 ZED X mini + 엣지 컴퓨터 ZED Box(Jetson Orin NX 16GB) + LTE 라우터 + 터치모니터
- 샘플링: 취득 시작 후 2초 안정화 → **2초당 1장** RGB/Depth 쌍 저장 → 작업자 종료(미조작 시 5분 후 자동 종료)
- 통신: 세션 종료 즉시 세종 NAS로 자동 업로드(rclone, 5분 주기 재시도). 원격 모니터링은 VPN(tailscale 주 / ZeroTier 예비)

**1-3. 부족한 데이터와 확보 계획**
**현장(실라인) 데이터가 부족.** 실험실 데이터는 8종 전부 확보했으나 현장 데이터는 2종만 확보됨. 실험실 데이터만으로 학습한 모델이 현장에서 성능이 급락(14%)하는 것이 확인되어 현장 데이터 확보가 최우선 과제.
확보 계획: 2026-07-29부터 용접 라인에 **무인 수집 시스템**을 설치·가동 중. 작업자가 도어 종류 버튼과 시작/종료만 누르면 자동 저장·업로드됨. 목표는 8종 전부, 가림 등 다양한 조건, 종당 2세션 이상. 현장 라벨은 CAD 기반 AI 판정과 교차 검증(실제 라벨 오류 1건을 AI가 검출한 사례 있음).

**1-4. 데이터 취득 설비/라인**
- 실험실(세종 사무소): 실물 도어 8종 촬영 — 1,256장
- **실운전라인(경주 공장 도어 용접 라인)**: 2026-04 수동 취득 78장, 2026-07-29~ 무인 수집 시스템 상설 운영(77장, 계속 축적 중)

**1-5. 확보 데이터 현황 (Raw / 라벨)**

| 데이터셋 | 출처 | 종류 수 | 수량(RGB+Depth 쌍) | 라벨 |
|---|---|---|---|---|
| 실험실 원본 | 세종, ZED X Mini | 8 | **1,256** | 완료 |
| 증강 1차 / 2차 | 원본 증강 | 8 | 1,256 / 1,256 | 완료 (강건성 평가 전용) |
| 현장 1차 | 경주, ZED 2i (2026-04) | 2 | **78** | 완료 (정정 이력 기록) |
| 현장 2차 | 경주, 무인 수집 (2026-07-29~) | 2 | **77** | 61장 미라벨(수동 라벨링 예정) |
| **합계** | | | **3,923** | |

- 분류 데이터는 폴더 단위 라벨이므로 Raw = 라벨 수량.
- 픽셀 단위 라벨(통풍구 영역) 1,256장은 **CAD 투영 정합으로 자동 생성** — 수작업 라벨링 0장.
- 학습/검증/시험 = 70/15/15 분할을 파일로 고정, 시험 데이터는 학습에서 완전 격리.

**1-6. 실시간 확보 여부**
**온프레미스로 실시간 확보 중.** 현장 장비 로컬 저장 → 세션 종료 시 세종 NAS 자동 업로드(중복 방지 마커, 실패 시 재시도, 원본 보존). 수집 서비스는 부팅 시 자동 시작·장애 시 자동 재시작.

**1-7. (옵션) 인스트럭션 셋 데이터**
해당 없음. 다만 라벨 외에 CAD 기반 설계 지식(치수·슬롯 수·종횡비)을 구조화하여 AI 판정에 활용 중.

## 2. 데이터 전처리

**2-1. 불필요 데이터 정의**
정의·자동 처리 중: 카메라 안정화 구간 제외, 흐린 프레임(블러 점수) 제외, CAD 정합 불량(IoU<0.8) 이미지 학습 제외, 라벨 미지정(Unknown) 세션 학습 제외. 촬영 프로토콜로 부적합 조건(도어 잘림, 한 프레임에 도어 2장, 클램프 가림 과다)을 정의.

**2-2. 전처리 기법**
- CNN: 깊이 기반 Edge 채널 합성(RGB+Edge 4채널), 리사이즈·정규화, 학습 시 온라인 증강
- 속성 파이프라인: 도어 영역 분리(MobileSAM) → 깊이 기반 정면 뷰 변환(2mm/px) → 노이즈 제거 → 축 정렬 → 종횡비 산출 → CAD 템플릿 정합 (6단계)
- 오프라인 증강 데이터는 학습이 아닌 강건성 평가 전용으로 규정

**2-3. 저장 표준 형태**
정의됨: `날짜/도어종류/세션/` 폴더에 `rgb_0000.png`, `depth_0000.png`, `meta.json`(종류·시각·수량·종료 사유), 전체 이벤트 로그 `events.jsonl`. 메타데이터 DB 스키마로 표준화.

**2-4. 표준 형태 가공 주체**
**수집 프로그램이 자동 수행.** 작업자는 버튼만 조작하며 파일명·폴더·메타데이터·업로드는 모두 자동. DB 등록도 스크립트로 자동.

**2-5. 데이터 품질 관리**
- RGB/Depth 쌍 정합성: 항상 쌍으로 저장, 수량 기록, DB 중복 등록 방지
- 라벨 정합성: AI 판정과 교차 검증(현장 55장 라벨 오류 검출·정정 사례), 세션 종료 시 종류 선택 자동 초기화로 오기 방지
- 업로드 누락: 마커+재시도+로그 / 저장 무결성: 세션 정상 종료 여부 기록 / 장비 이상: 카메라 자동 재연결, 디스크 잔량 경고

**2-6. 품질 기준 관리**
문서화된 기준: 촬영 프로토콜(도어 전체 프레임 내, 프레임당 1장, 가림 최소화, 도어당 10프레임 이상), 학습 사용 기준(정합 IoU≥0.8, 블러 통과), 평가 방법론(3분할 격리, 증강 학습 금지, 현장 별도 평가), 라벨 정정 이력 기록 규칙.

## 3. 데이터 저장 및 관리

**3-1. 저장소 및 스펙**
3계층 온프레미스: ① 현장 엣지(ZED Box, 1차 저장) → ② **세종 NAS Synology DS1522+ 20TB(정본)** → ③ 학습 PC(RTX 5090, 학습 데이터 + 메타데이터 DB). 이미지는 파일로, 메타데이터는 DB로 관리하는 하이브리드 구조.

**3-2. 메타데이터 충분성**
DB 9개 테이블로 데이터→학습→평가 전 과정 추적: 데이터셋/종류/이미지(경로·해상도·깊이 단위·블러·출처·분할), 촬영 세션(카메라·해상도·주기·수량·종료 사유), 모델/학습 세션/에폭별 지표(아키텍처·하이퍼파라미터·GPU), 평가 결과(정확도·F1·혼동행렬). 학습·평가 스크립트 실행 시 **자동 기록**.

**3-3. 주기적 모니터링**
세종에서 VPN으로 현장 화면·프리뷰·당일 통계·로그를 **1일 2회** 원격 확인. 운영 중 발견한 장애(부팅 시 GPU 미준비, 시계 미동기화)는 자동 대응 로직으로 해결 완료. DB는 웹 브라우저로 열람.

**3-4. 확장성**
- 데이터 확장: 폴더 규칙 + 멱등 등록으로 재스캔만으로 추가
- 부품 확장: 신규 부품/리비전은 **CAD 파일 1개 추가**로 대응(재학습 불필요)
- 사이트/라인 확장: 설치 스크립트 1회 실행으로 배포, NAS 세션 트리 구조로 사이트 추가 가능
- 모델 확장: DB가 아키텍처 무관 설계(현재 CNN·U-Net 두 계열 기록)
- 로드맵: 1단계 SQLite(완료) → 2단계 현장 서버 DB 연동 → 3단계 학습·평가 자동 기록(완료) → 4단계 PostgreSQL·다중 사용자

## 4. AI 모델

**4-1. 참조 모델**
ResNet18(ImageNet 사전학습; RGB/RGB-D/RGB+Edge 입력 비교 후 RGB+Edge 채택), MobileSAM(영역 분리), U-Net(통풍구 세그멘테이션). CAD 점군 정합(ICP) 기반 분류는 검토 후 기각(절대 치수 신뢰 불가).

**4-2. 벤치마크 성능 (현재 수준)**

| 모델 | 실험실 시험셋 | 증강 1차 | 증강 2차 | 현장 |
|---|---|---|---|---|
| CNN 분류 | **100%** | 92.1% | 93.7% | 14.1% |
| CAD 속성 파이프라인 (그룹 / 종류) | 100% / **99.2~99.7%** | 97.7 / 95.5% | 95.5 / 93.6% | **100%** / 21.9% |

- 과제 목표 **인식률 99% 이상**: 실험실 조건 달성. 현장 조건은 데이터 재수집 후 재평가 예정.
- 현장 종류 정확도 저하 원인은 촬영 프로토콜 위반(도어 잘림·이중 배치·클램프 가림)으로 규명 — 알고리즘 한계 아님. (위치 정도 3mm 목표는 본 분류 업무 외 항목)

**4-3. 검증 시나리오**
실험실 시험셋(격리) → 증강 강건성 → 현장 외부셋의 3단계 평가(부트스트랩 2,000회). 실시간 추론 서버 2종(웹 UI)으로 카메라 라이브 판정, 재생 모드로 현장 세션 재검증. 향후 현장 재수집 데이터로 세션 단위 평가 및 두 모델 하이브리드(불일치 시 판정 보류).

**4-4. 타 공정 적용 가능성**
속성 파이프라인은 CAD에서 판별 기준을 자동 생성하므로 CAD가 있는 판금 부품이면 적용 가능하고, CNN은 라벨 데이터만 있으면 재학습으로 적용 가능. 수집·관리 체계는 부품 무관. (실제 타 공정 적용 사례는 아직 없음 — 가능성 수준)

**4-5. 알고리즘과 성능**
- CNN: ResNet18, RGB+Edge 4채널 448×448, Adam, 조기 종료. 실험실 100%, 현장 14.1%
- 속성 파이프라인: MobileSAM → 정면 뷰 변환 → U-Net 통풍구 검출(라벨 CAD 자동 생성) → CAD 템플릿 정합(그룹) × 종횡비(종류) → 10프레임 집계. 실험실 99.2~99.7%, 현장 그룹 100%. 추론 약 170ms/프레임(RTX 5090)

**4-6. 지속 개선 프로세스**
학습·평가 전 과정 스크립트화(시드·분할 고정으로 재현), 실행별 산출물 보관, 결과 DB 자동 기록으로 모델 간 비교 가능, 신규 데이터 상시 유입 경로, 원리·함정·프로토콜 문서화.

**4-7. 기존 기술 대비 개선점 (기존 Vision/AI 기술 대비)**
- 규칙 기반 Vision(슬롯 카운팅·에지 검출)은 조명·반사로 프레임별 편차가 커 불안정 → CAD 정합 라벨로 학습한 세그멘테이션으로 안정화
- 일반 CNN 분류는 개체 외관을 암기해 현장에서 붕괴(14%) → CAD 설계 속성 기반 판별로 현장 그룹 판별 **50% → 100%**
- 수작업 픽셀 라벨링 0장(CAD 자동 생성), 신규 부품 대응이 재학습 없이 CAD 추가로 완료, 카메라 기종 변경(ZED X mini↔2i)에도 판정 불변
- AI가 사람의 라벨 오류를 검출·정정한 사례 확보

**4-8. 현장 적용 성과**
현재는 현장 **데이터 수집 시스템 적용 단계**(모델의 공정 상시 적용 전). 성과: 용접 라인 무인 수집 시스템 설치·가동 및 작업자 설명서 배포, 실험실 모델의 현장 한계를 정량 확인하고 대안 검증, 현장 라벨 오류 검출·정정.

**4-9. 성능 개선 계획**
현장 8종 재수집 완료 후 CNN을 실험실+현장 혼합 데이터로 재학습(세션 단위 평가), 속성 파이프라인은 판정 보류 게이트로 병행(하이브리드), 현장 데이터 축적 시 치수 기준값 재보정, 촬영 프로토콜 현장 재점검.

**4-10. 추가 개발 기능**
실시간 서버 하이브리드 통합(불일치 시 보류), 엣지(Jetson Orin NX) 추론 최적화(현재 1초/프레임, 최적화 옵션 구현 완료·실측 예정), 현장 수집 서버의 DB 직접 연동.

## 5. AI 인프라

**5-1. SW 인프라(MLOps)**
구축: 수집 서비스 자동화(systemd·NAS 자동 업로드), 메타데이터 DB·인제스트·웹 열람, 재현 가능한 학습·평가 파이프라인과 결과 자동 기록, 실시간 추론 서버, git 형상 관리. 미구축: 실험 추적 도구, 자동 재학습 트리거, 모델 레지스트리.

**5-2. 엣지컴퓨팅 계획**
현장 ZED Box(**Jetson Orin NX 16GB**)를 수집 장비로 운용 중이며 동일 장비에서 추론 실측·최적화 진행. 최종 추론 위치(엣지 vs 서버)는 최적화 실측 결과에 따라 결정.

**5-3. GPU 인프라**
학습 PC **RTX 5090(32GB)**, Core Ultra 9 285K, RAM 62GB — 학습·평가·추론 서버·DB 운용. 현장 엣지 GPU는 Jetson Orin NX.

**5-4. 최종 운영 환경**
**온프레미스.** 현장 엣지 — 세종 NAS — 세종 학습 PC 구성, 사이트 간 VPN 연결. 추론 서버는 현재 세종 사무소에서 운영. 클라우드 사용 계획 없음.
