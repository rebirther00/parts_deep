## 1. 데이터 종류 및 확보

**1-1. 필요한 제조 데이터 정의**
도어 8종(차종×위치)을 인식하기 위해 **RGB+Depth 이미지 쌍**을 표준 데이터로 정의. 판별 기준(외형 치수, 슬롯 수·배치)을 CAD에서 추출해 스펙 파일로 관리.

**1-2. 실라인 데이터 스펙**
경주 공장 용접 라인에 무인 수집 시스템 **정식 설치·가동 중(2026-08-27~)**. 작업자 조작으로 자동 저장 → 세종 NAS 자동 업로드되는 체계로 구성.
- 장비: 스테레오 깊이 카메라 ZED X mini + 엣지 컴퓨터 ZED Box(Jetson Orin NX 16GB) + LTE 라우터 + 터치모니터
- 샘플링: 취득 시작 후 2초 안정화 → 2초당 1장 RGB/Depth 쌍 저장 → 작업자 종료(미조작 시 5분 후 자동 종료)
- 통신: 세션 종료 즉시 NAS 자동 업로드(rclone, 5분 주기 재시도), 원격 모니터링 VPN(tailscale 주 / ZeroTier 예비)

**1-3. 부족한 데이터와 확보 계획**
**현장(경주) 데이터 부족이 핵심 과제** — 데이터 수집 시스템(2026-08-27~ 가동 중)으로 8종 데이터 재수집 후 재평가 예정. 8/31 기준 7종 확보, 잔여 1종(E25 앞문)은 생산 순서에 따라 유입 시 수집.

**1-4. 데이터 취득 설비/라인**
세종 실험실(ZED X Mini)에서 취득. 경주 공장 실라인은 2026-08-27부터 취득 중.

**1-5. 확보 데이터 현황 (Raw / 라벨)**

| 구분 | 수량 | 라벨 |
|---|---|---|
| 실험실 원본(8종 전부) | 1,256장 | 완료 |
| 증강 1·2차(강건성 평가 전용) | 2,512장 | 완료 |
| **소계(실험실)** | **3,768장** | 전량 완료 |
| 현장(무인 수집, 2026-08-27~) | **8종 중 7종, 31세션 2,708쌍** (8/31 기준) | 작업자 버튼 라벨 + AI 교차 검증 |

**1-6. 실시간 확보 여부**
**온프레미스로 실시간 확보 중.** 데이터 수집 시스템 가동 중(2026-08-27~)이며, 가동 시 세종 NAS로 자동 업로드되는 실시간 체계로 전환 완료.

**1-7. (옵션) 인스트럭션 셋 데이터**
도어 인식 결과(종류, 좌표, 판별 근거)를 CAD 스펙 정보와 연계하여 관리하고 있어, 인스트럭션 셋 데이터로 가공할 수 있는 기초 여건은 마련되어 있음. 다만 현재는 별도의 인스트럭션 셋 형태로 정리된 산출물은 없으며, 무인 수집 시스템을 통한 실환경 데이터 축적 이후 필요성을 검토할 예정.

## 2. 데이터 전처리

**2-1. 불필요 데이터 정의**
정의하여 처리 중: 카메라 안정화 구간 제외, 실험실 취득 시 블러 점수 임계값 미만 프레임 제외, CAD 정합 불량(IoU<0.8) 이미지는 학습에서 자동 제외, 한 프레임에 도어 2장은 학습 미사용, Unknown 라벨 세션은 학습 미사용.

**2-2. 전처리 기법**
CNN은 깊이 기반 Edge 채널 합성(RGB+Edge 4채널)·리사이즈·정규화·온라인 증강, 홀 판별기는 1280×768 letterbox + 회전 ±180° 증강을 적용. 오프라인 증강 데이터는 학습이 아닌 **강건성 평가 전용**으로 규정.

**2-3. 저장 표준 형태**
정의 완료·운영 중: `날짜/도어종류/세션/` 폴더에 RGB·Depth 쌍 + meta.json(종류·시각·수량·종료 사유). 해상도 1920×1200, 깊이 mm 단위 16비트. 메타데이터 DB 스키마로 표준화되어 현장→NAS→학습 PC까지 동일 규칙 적용.

**2-4. 표준 형태 가공 주체**
**수집 프로그램이 자동 수행** — 작업자는 버튼 조작만 하며 파일명·폴더·메타데이터·업로드·DB 등록이 전부 자동. 수동 작업은 홀 랜드마크 라벨 134장(자체 도구, 약 1시간 수행)뿐.

**2-5. 데이터 품질 관리**
RGB/Depth 쌍 정합·수량 기록, 업로드 마커+재시도+로그, 세션 정상 종료 여부 기록, 카메라 자동 재연결·디스크 잔량 경고로 관리 중. 라벨은 AI 판정과 교차 검증.

**2-6. 품질 기준 관리**
촬영 프로토콜(도어 전체 프레임 내, 프레임당 1장, 도어당 10프레임 이상), 학습 사용 기준(CAD 정합 IoU≥0.8, 블러 통과), 평가 방법론(3분할 격리, 증강 학습 금지, 현장 별도 평가), 라벨 정정 이력 기록 규칙.

## 3. 데이터 저장 및 관리

**3-1. 저장소 및 스펙**
NAS(DS1522+, 20TB)를 정본으로 현장 장비 → NAS → 학습 PC 구조로 관리.

**3-2. 메타데이터 충분성**
메타데이터 DB로 데이터·학습·평가 이력을 자동 기록.

**3-3. 주기적 모니터링**
실시 중 — 세종에서 VPN으로 현장 화면·프리뷰·당일 통계·로그를 **1일 2회** 원격 확인. DB는 웹 브라우저로 열람.

**3-4. 확장성**
파일명·폴더 규칙 등록으로 데이터 추가는 재스캔만으로 대응, 신규 부품/리비전은 CAD 파일 추가로 대응 가능(재학습 불필요), 타 사이트·라인은 설치 스크립트 1회 실행으로 배포 가능.

## 4. AI 모델

**4-1. 참조 모델**
CNN 분류(ResNet18, RGB+Edge) 및 홀 랜드마크 검출기(ResNet18-FPN 히트맵) + CAD 치수 대조 판정기.

**4-2. 벤치마크 성능 (현재 수준)**
실험실 조건 목표(99% 이상) 달성 — CNN 100%, CAD 파이프라인 99.2~99.7%. 현장 조건은 현재 홀 판별기로 평가 진행 중.

**4-3. 검증 시나리오**
3단계 평가 체계: 실험실 시험셋(세션 단위 70/15/15 분할, 학습에서 격리) → 증강 강건성(증강 데이터는 학습 금지·평가 전용) → 현장 외부셋 평가로 1차년도 진행.

**4-4. 타 공정 적용 가능성**
현재 모델은 8종 도어 인식에 특화되어 있으나, RGB+Depth 기반 객체 인식 구조 및 CAD 속성 연계 판별 방식은 형상·치수 정보가 있는 타 부품 인식에도 동일한 방법론으로 확장 적용이 가능할 것으로 판단됨. 다만 현재까지 타 부품·공정 적용 실적은 없음.

**4-5. 알고리즘과 성능**
CNN(ResNet18) 및 홀 랜드마크 판별기(ResNet18-FPN 히트맵, 홀 단계 41ms/프레임) 현장 판정 100%.

**4-6. 지속 개선 프로세스**
학습·평가 전 과정을 스크립트화(시드·분할 고정으로 재현 가능)하고 결과를 DB에 자동 기록해 모델 간 비교 가능. 현장 무인 수집→NAS→DB 인제스트의 신규 데이터 상시 유입 경로 구축 완료.

**4-7. 기존 기술 대비 개선점**
기존에는 작업자가 육안으로 도어 종류를 확인·분류하여 작업 속도 및 정확도가 작업자 숙련도에 좌우되는 한계가 있었음. 본 과제에서는 RGB+Depth 영상 기반 AI 인식과 CAD 속성 연계 판별로 도어 종류를 자동·정량적으로 판별할 수 있는 가능성을 실험실 조건에서 확인하였으며, **판별 근거를 치수·형상 데이터로 추적할 수 있는 구조**를 확보.

**4-8. 현장 적용 성과**
경주 공장 용접 라인에 무인 수집 시스템 설치·가동(2026-08-27~) 및 작업자 설명서 배포. 수집 데이터에 대한 정량 검증 완료 — **2026-08-31 기준 판정 646/646 정답**, 도어가 없는 빈 지그 9장은 전량 보류(오판 0)로 정상 동작 확인.

**4-9. 성능 개선 계획**
① 잔여 1종(E25 앞문) 현장 수집으로 8종 검증 완결 ② 카메라 실측 캘리브레이션 반영으로 거리 측정 정밀화 ③ 엣지(Jetson) TensorRT 배포로 취득 세션마다 자동 판정·DB 기록.
이 외에 부품 위치 및 자세 추정 모델 개발, 자동화 라인(로봇) 연계 가능한 파이프라인 구축, 도장 라인 등 추가 부품 분류가 필요한 라인 확장 적용.

**4-10. 추가 개발 기능**
도어 6DoF 위치·자세 추정 기능(로봇 연계 대비) — **1차 구현 완료**, 현장 데이터 280프레임에서 잔차 중앙값 3.2~4.7mm 수준이며 실험실 레벨에서 레이저 트래커 실측(GT)을 통한 검증 예정.
