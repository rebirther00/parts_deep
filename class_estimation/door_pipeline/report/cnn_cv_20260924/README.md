## 판단
- **레시피 채택 확정**(sqrt 가중치 기본, `--class_weight inv` 로 이전 재현). 폴백 CNN 재학습(신규 세션 누적 후 seed916 교체 시)은 이 레시피로.
- 후속 실험(선택): 초반 스파이크 제거 — `--lr 3e-4` 또는 1~2에폭 warmup. 우선순위 낮음(결과에 영향 없었음).
- 학습 속도: DataLoader 워커 4개 × 49스레드(cv2/numpy 스레드)로 24코어에 ~200스레드 → load 100+, 에폭 7~16분. 워커 내 `cv2.setNumThreads(0)`·`torch.set_num_threads(1)` 로 제한하면 에폭 시간 단축 예상(미적용, 다음 학습 전 적용 권장).
- 다중과제 CNN(door_partno, seed916 미세조정)은 이미 sqrt 가중치를 쓰므로 변경 없음. 레이더·품번은 4채널 검출기+규칙이 담당(CNN 미채택).
