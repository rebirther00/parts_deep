# K_DEPTH 재유도 분석 (2026-09-16) — 홀 판별기 D 의 잔차 스케일을 실측 intrinsics 경로에서 현장 83세션으로 재적합

목적: TODO 7 "K_DEPTH 상수를 실측 intrinsics 기반으로 재유도". FRT 3종 마진(41~47mm) 대비 D 오차 여지 축소.
데이터: `datasets_factory_v2/all` 1,773프레임(83세션, 세션당 최대 20장, 9종) → 판정 프레임 1,748. 도구 `tools/analyze_k_depth.py`, 프레임별 결과 `frames.json`.

## 결론
1. **실측 intrinsics 자체는 D 를 거의 안 바꾼다.** legacy(fx=1065, 주점=영상 중심, ×K_DEPTH 0.8505) 대비 실측(fx=1269.746, cx 961.7, cy 598.6) 역투영 후 같은 환산 K(1.0140)를 곱하면 D 차이 중앙값 +1.2mm. 배율은 상쇄되고 주점 오프셋 효과만 남는다.
2. **효과는 잔차 K 재적합에서 나온다.** 기존 K(1세션 E25_RH 로 캘리브)는 전 클래스 편차가 양수(전역 +6.6mm). 83세션 K=CAD/D_raw 의 중앙값 **1.0064** 로 바꾸면:

| | 편차 med | \|편차\| p95 | max | 판정 정확도 | 마진 p5 |
|---|---|---|---|---|---|
| 기존 (K 1.0140) | +6.6 | 18.3 | 24 | 1746/1748 | 27.3 |
| **재적합 (K 1.0064)** | +0.1 | **11.8** | 18 | 1746/1748 | **35.4** |

   클래스별 잔여 편차: E38_LH_FRT +9.2, E30_E38_RH +4.9, E30_LH_FRT +1.4, E25_RH +0.2, E23 +1.0, E25_LH_RR −4.3, E30_LH_RR −5.3, E25_LH_FRT −6.0(1세션), E38_LH_RR −8.6. 세션 leave-one-out 으로 K 를 맞춰도 1742/1744 로 과적합 없음.
3. **남은 오차의 정체 = 세션 단위 depth 스케일 요동(±0.6%, 최대 ±1.5%).** 세션 K 가 코너 홀 평면 깊이 z(1443~1474mm)와 **−0.95 상관**: 평면이 20mm 멀게 측정된 세션은 D 가 1.4% 크게 나온다. 도어가 실제로 움직인 것이면 D 는 불변이어야 하므로, **depth 자체가 세션마다 ±10~20mm 편향**되고 그 비율만큼 D 에 전파되는 것으로 해석된다. 시각(−0.34)·날짜(1.001~1.013)와의 상관은 약함 → 온도/조명 가설은 미확정.
4. 자세 파이프라인의 depth_scale(1.0140, PnP 대조 Δz +1.3mm 로 확인)과 0.75% 불일치. 판별기 K_CAMERA 만 갱신하고 pose_utils 는 유지 — 레이저 트래커 GT 로 판가름할 항목.

## 적용 (코드)
- `hole_classifier.K_CAMERA[54910212] = 1.0064` (현장 카메라 시리얼). 18 실시간 서버는 ZED calib 의 serial 로 자동 적용.
- `camera_utils.KNOWN_CAMERAS`(pose_utils 에서 이동) + `intrinsics_for_image(path, shape)`: 세션 meta.json → 해상도 매칭 → None.
- `17_evaluate_hole_classifier.py --intrinsics auto`(기본): 저장 이미지 평가도 실시간과 같은 경로(실측 intrinsics + K_CAMERA). `none` = 이전 방식.
- K_DEPTH[1200](legacy)는 pose_utils depth_scale 이 참조하므로 그대로 둠. 사무실 1080p 데이터는 시리얼 미기록 → legacy 경로 유지.
