## 4. 관찰 및 후속

1. **RH 계열 +8~12mm 일관 편향** (E25_RH, E30_E38_RH). RR 계열은 ±4mm 이내. 판정에는 영향 없으나 E30_E38_RH의 최소 마진(32.9mm)이 가장 작으므로, 세션이 더 쌓이면 `K_DEPTH`(카메라 모드별 스케일 보정) 또는 RH 그룹 오프셋 재보정 검토.
2. **FRT 계열 마진 주의**: FRT 3종은 CAD 간격이 41~47mm라 E30_LH_FRT 최소 마진 24.9mm. 나머지 FRT 2종(E25, E38) 현장 데이터 확보가 최우선.
3. **정답 라벨은 작업자 입력**이며 별도 육안 검증은 없음. 다만 4클래스 모두 D 중앙값이 해당 CAD에 가장 가까워 라벨 오류 정황 없음.
4. Unknown 4세션(7/29·8/4·8/11, 61장)은 설치 전 사무실 시험 촬영으로 확인되어 `is_valid=0` 처리(도어 데이터 아님).
5. 홀 판별기 재학습은 현 시점 불필요. `datasets_factory_v2/train`(212장)은 RGBE CNN fine-tune용으로 보관.
