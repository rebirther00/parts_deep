## 1. 개요

본 연구는 굴착기 제조 공정의 생산성 향상을 목표로, AI 기반 부품 인식 및 위치 추정 시스템을 개발하였습니다. 1차년도에는 다음과 같은 핵심 과제를 수행하였습니다:

- **부품 분류(Classification)**: 굴착기 부품 이미지를 입력받아 부품 종류를 자동으로 분류

## 2. 부품 인식 및 위치 추정 데이터 항목 정의 및 AI 모델 구축

### 2.1 공정 흐름 기반의 부품 인식 및 위치 추정을 위한 데이터 항목 정의

#### 2.1.1 입력 데이터 항목

| 항목 | 형식 | 설명 |
|------|------|------|
| RGB 이미지 | PNG (1024×1024) | 부품이 촬영된 컬러 이미지 |
| Depth 맵 | NPY (1024×1024, float32) | 카메라로부터의 거리 정보 (미터 단위) |
| 2D Bounding Box | NPY + JSON | 이미지 내 부품 위치 좌표 |

#### 2.1.2 출력 데이터 항목 (라벨)

| 항목 | 형식 | 설명 |
|------|------|------|
| 클래스명 | String | 부품 종류 (arm_link_25_nomat, arm_link_30_notmat, boom_link_25_nomat, boom_link_30_notmat) |
| 3D 위치 (camTobj) | [x, y, z] 미터 | 카메라 좌표계에서 부품 중심까지의 거리 |
| 3D 회전 | [roll, pitch, yaw] degrees | 카메라 좌표계에서 부품의 자세 |
| Visibility | Float (0~1) | 부품 가시성 비율 |

### 2.2 AI 모델 구축을 위한 하이퍼파라미터 및 학습 데이터 전처리 기법 조사

#### 2.2.1 부품 분류 모델 (Classification)

**모델 아키텍처**: ResNet18 (Transfer Learning)

| 하이퍼파라미터 | 값 | 설명 |
|----------------|-----|------|
| Backbone | ResNet18 | ImageNet 사전학습 가중치 사용 |
| 입력 크기 | 224×224 | ResNet 표준 입력 크기 |
| 배치 크기 | 32 (자동 조정) | GPU 메모리에 따라 자동 조정 |
| 학습률 | 0.001 | Adam 옵티마이저 |
| 에포크 | 30 | Early Stopping 적용 (patience=5) |
| Dropout | 0.5, 0.3 | FC 레이어에 적용 |

**FC 레이어 구조**:
```
ResNet18 Feature Extractor (512 features)
    ↓
Dropout(0.5)
    ↓
Linear(512 → 256) + ReLU
    ↓
Dropout(0.3)
    ↓
Linear(256 → 4 classes)
```

**데이터 전처리**:
- Resize: 1024×1024 → 224×224
- 정규화: ImageNet mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]
- BBox Crop (선택적): 배경 제거를 위한 부품 영역 크롭

#### 2.2.2 위치 추정 모델 (6DoF Pose Estimation)

**모델 아키텍처**: DenseFusion 방식 (RGB + Depth 융합)

| 하이퍼파라미터 | 값 | 설명 |
|----------------|-----|------|
| RGB Encoder | ResNet50 | 이미지 특징 추출 |
| Depth Encoder | Custom CNN | Depth 특징 추출 |
| 융합 방식 | Concatenation | RGB + Depth 특징 결합 |
| 배치 크기 | 8~16 | GPU 메모리 제약 |
| 학습률 | 5e-5 ~ 1e-4 | Adam 옵티마이저 |
| 에포크 | 100~150 | |

**위치 출력**:
- 3D Translation: (x, y, z) 미터 단위
- 3D Rotation: 6D Rotation Representation → Quaternion/Euler 변환

**좌표계 정의** (OpenCV/Depth 좌표계):
- X: 오른쪽 (+)
- Y: 아래쪽 (+)
- Z: 앞쪽 (+, forward)

### 2.3 데이터 증강 기법 및 모델 경량화 기술 조사

#### 2.3.1 적용된 데이터 증강 기법

| 기법 | 파라미터 | 적용 대상 |
|------|----------|-----------|
| **Domain Randomization** | - | 합성 데이터 생성 시 |
| - 배경 색상 랜덤화 | 회색~갈색 계열 | 바닥/벽 |
| - 조명 위치 랜덤화 | 부품 중심 기준 다양한 위치 | Dome Light, Point Light |
| - 카메라 위치 랜덤화 | 사선 구도 (측면+윗면) | 카메라 |
| **학습 시 증강** | - | 분류/위치 추정 |
| RandomHorizontalFlip | p=0.3~0.5 | 분류 |
| RandomRotation | 15° | 분류 |
| ColorJitter | brightness=0.2, contrast=0.2 | 분류/위치 |
| Gaussian Noise (Depth) | σ=0.02 | 위치 추정 |

#### 2.3.2 모델 경량화 전략

| 전략 | 적용 여부 | 설명 |
|------|-----------|------|
| Transfer Learning | ✓ | ImageNet 사전학습 가중치 활용 |
| ResNet18 사용 | ✓ | ResNet50 대비 경량 |
| Dropout | ✓ | 과적합 방지 및 모델 일반화 |
