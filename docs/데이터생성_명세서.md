## 1. 개요

### 1.1 목적

본 명세서는 NVIDIA Isaac Sim을 활용하여 굴착기 부품 인식 및 위치 추정 AI 모델 학습용 합성 데이터셋을 생성하는 방법을 정의합니다.

### 1.2 합성 데이터의 장점

| 장점 | 설명 |
|------|------|
| 대량 생성 | 수천~수만 장의 이미지를 자동 생성 |
| 완벽한 라벨 | 정확한 Ground Truth 자동 생성 |
| 다양성 확보 | Domain Randomization으로 다양한 조건 시뮬레이션 |
| 비용 절감 | 실제 촬영/라벨링 비용 없음 |
| 재현성 | 동일 조건에서 반복 생성 가능 |

### 1.3 생성 파이프라인 개요

```
[USD 부품 모델] → [Isaac Sim 로드] → [시뮬레이션 설정]
                                           ↓
                              [Domain Randomization 적용]
                                           ↓
                              [Replicator로 렌더링]
                                           ↓
[RGB 이미지] + [Depth 맵] + [BBox] + [Pose 라벨] → [파일 저장]
```

## 6. Domain Randomization 명세

### 6.1 개요

Domain Randomization은 **Sim-to-Real 전이**를 개선하기 위해 시뮬레이션에서 다양한 조건을 랜덤하게 적용하는 기법입니다.

### 6.2 랜덤화 항목

#### 6.2.1 카메라 위치

```python
# 카메라 위치 랜덤화 (사선 구도)
with rep.create.group([camera]):
    rep.modify.pose(
        position=rep.distribution.uniform(
            (part_center[0] + camera_distance_max * 0.3,   # X min
             part_center[1] + camera_distance_max * 0.1,   # Y min
             part_center[2] + camera_distance_max * 0.2),  # Z min
            (part_center[0] + camera_distance_max * 0.7,   # X max
             part_center[1] + camera_distance_max * 0.5,   # Y max
             part_center[2] + camera_distance_max * 0.4)   # Z max
        ),
        look_at=part_center  # 항상 부품 중심을 바라봄
    )
```

| 파라미터 | 범위 | 단위 |
|----------|------|------|
| X 오프셋 | 0.3 ~ 0.7 × camera_distance_max | m |
| Y 오프셋 | 0.1 ~ 0.5 × camera_distance_max | m |
| Z 오프셋 | 0.2 ~ 0.4 × camera_distance_max | m |

#### 6.2.2 배경 색상

```python
# 바닥 색상 (공장 환경: 회색~갈색)
with floor_plane:
    rep.randomizer.color(
        colors=rep.distribution.uniform(
            (0.2, 0.2, 0.2),  # 어두운 회색 (RGB)
            (0.6, 0.5, 0.4)   # 밝은 갈색/베이지 (RGB)
        )
    )

# 벽 색상 (공장 환경: 회색~베이지)
with back_wall:
    rep.randomizer.color(
        colors=rep.distribution.uniform(
            (0.4, 0.4, 0.4),   # 회색 (RGB)
            (0.9, 0.9, 0.85)   # 밝은 베이지 (RGB)
        )
    )
```

#### 6.2.3 조명 위치

```python
# 주 조명 위치
with point_light1:
    rep.modify.pose(
        position=rep.distribution.uniform(
            (part_center[0] + part_size * 0.5,    # X min
             part_center[1] - part_size,           # Y min
             part_center[2] + part_size * 1.5),    # Z min
            (part_center[0] + part_size * 1.5,    # X max
             part_center[1] + part_size,           # Y max
             part_center[2] + part_size * 3)       # Z max
        )
    )
```

## 7. 데이터 형식 상세

### 7.1 RGB 이미지

| 항목 | 값 |
|------|-----|
| 형식 | PNG (무손실) |
| 해상도 | 1024×1024 픽셀 |
| 채널 | RGB (3채널) 또는 RGBA (4채널) |
| 비트 깊이 | 8bit per channel |
| 파일명 패턴 | `rgb_####.png` (4자리 숫자) |

### 7.2 Depth 맵

| 항목 | 값 |
|------|-----|
| 형식 | NumPy (.npy) |
| 데이터 타입 | float32 |
| 해상도 | 1024×1024 |
| 채널 | 1채널 (또는 3채널 중 첫 번째 사용) |
| 단위 | 미터 (meters) |
| 유효 범위 | 0.01m ~ 100m |
| 무효값 | inf 또는 0 |
| 파일명 패턴 | `distance_to_camera_####.npy` |

### 7.3 2D Bounding Box

**NPY 파일 구조** (`bounding_box_2d_tight_####.npy`):
```python
# 구조화된 배열 (structured array)
dtype = [
    ('semanticId', np.int32),
    ('x_min', np.float32),
    ('y_min', np.float32),
    ('x_max', np.float32),
    ('y_max', np.float32),
    ('occlusionRatio', np.float32)
]
```

**라벨 매핑** (`bounding_box_2d_tight_labels_####.json`):
```json
{
  "1": {"class": "arm_link_25_nomat"},
  "2": {"class": "background"}

```

### 7.4 좌표계 정의

#### USD/OpenGL 좌표계 (시뮬레이션 내부)
```
Y (위 +)
|
|
+------→ X (오른쪽 +)
/
Z (뒤 +, backward)
```

#### OpenCV/Depth 좌표계 (출력 데이터)
```
Y (아래 +)
|
|
+------→ X (오른쪽 +)
/
Z (앞 +, forward)
```

**변환 공식**:
```python
# USD → OpenCV 변환
camTobj_opencv = [
    camTobj_usd[0],    # X 유지
    -camTobj_usd[1],   # Y 반전
    -camTobj_usd[2]    # Z 반전
]
```

### 9.3 통계 검증 스크립트

```python
import os
import json
import glob
import numpy as np
from PIL import Image

def verify_dataset(dataset_dir):
    """데이터셋 품질 검증"""
    class_dirs = [d for d in os.listdir(dataset_dir) 
                  if os.path.isdir(os.path.join(dataset_dir, d))]
    
    for class_name in class_dirs:
        class_dir = os.path.join(dataset_dir, class_name)
        
        # 파일 개수 확인
        rgb_files = glob.glob(os.path.join(class_dir, "rgb_*.png"))
        depth_files = glob.glob(os.path.join(class_dir, "distance_to_camera_*.npy"))
        pose_files = glob.glob(os.path.join(class_dir, "pose_*.json"))
        
        print(f"\n{class_name}:")
        print(f"  RGB: {len(rgb_files)}장")
        print(f"  Depth: {len(depth_files)}장")
        print(f"  Pose: {len(pose_files)}개")
        
        # 이미지 크기 확인 (첫 번째 파일)
        if rgb_files:
            img = Image.open(rgb_files[0])
            print(f"  RGB 크기: {img.size}")
        
        # Depth 유효성 확인 (첫 번째 파일)
        if depth_files:
            depth = np.load(depth_files[0])
            valid_ratio = np.sum(np.isfinite(depth) & (depth > 0)) / depth.size
            print(f"  Depth 유효 비율: {valid_ratio*100:.1f}%")
        
        # Pose 필드 확인 (첫 번째 파일)
        if pose_files:
            with open(pose_files[0]) as f:
                pose = json.load(f)
            required_fields = ['class_name', 'camTobj', 'bbox_2d', 'image_info']
            missing = [f for f in required_fields if f not in pose]
            if missing:
                print(f"  ⚠️ 누락 필드: {missing}")
            else:
                print(f"  ✓ Pose 필드 완전")

# 사용
verify_dataset("pos_estimation/dataset_pos_depth")
```
