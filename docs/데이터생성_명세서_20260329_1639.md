## 1. 개요

### 1.1 목적

본 명세서는 ZED X Mini RGBD 카메라를 활용하여 굴착기 도어 부품 분류 AI 모델 학습용 실물 데이터셋을 생성하는 방법을 정의한다. 8종의 도어 부품에 대해 RGB 이미지, Depth 맵, SAM 기반 전경 마스크를 포함하는 멀티모달 데이터셋을 구축한다.

### 1.2 실물 데이터 기반 접근의 배경

| 항목 | 설명 |
|------|------|
| 도메인 일치 | 실제 배치 환경과 동일한 촬영 조건 (조명, 배경, 카메라 거리) |
| Depth 활용 | Neural Depth 모드로 정밀 깊이 측정 → 3D 물리 치수 추출 |
| SAM 마스크 | 자동 전경 분리로 수동 라벨링 비용 제거 |
| 증강 파이프라인 | 온라인/오프라인 2단계 증강으로 일반화 성능 확보 |

### 1.3 데이터 생성 파이프라인 개요

```
[ZED X Mini 카메라] → [Flask 캡처 UI] → [RGBD 이미지 쌍 저장]
                                                ↓
                                    [SAM2 전경 마스크 생성]
                                                ↓
                        [RGB + Depth + Mask] → [원본 데이터셋]
                                                ↓
                              ┌─────────────────┴─────────────────┐
                              ↓                                   ↓
                    [온라인 증강 (학습 시)]              [오프라인 증강 (사전 생성)]
                    - Flip, Rotation, Scale             - Brightness, Contrast
                    - Color Jitter                      - Hue, Noise, Blur
                    - Gaussian Noise/Blur               - mask_only / 전체
                              ↓                                   ↓
                    [모델 학습/평가]                    [증강 데이터셋 평가]
```

## 4. 분류용 데이터셋 명세

### 4.1 촬영 스크립트

**파일**: `01_capture_dataset.py`

Flask 기반 웹 UI를 통해 실시간 카메라 스트리밍을 확인하면서 도어 부품을 클래스별로 촬영한다.

### 4.2 촬영 설정

```python
# 대상 클래스 목록
CLASSES = [
    "E25_door_LH_FRT", "E25_door_LH_RR", "E25_door_RH",
    "E30_door_LH_FRT", "E30_door_LH_RR",
    "E30_E38_door_RH",
    "E38_door_LH_FRT", "E38_door_LH_RR",
]

# 카메라 설정 (camera_utils.py)
CAMERA_RESOLUTION = sl.RESOLUTION.HD1080   # 1920×1080
CAMERA_FPS = 30
DEPTH_MODE = sl.DEPTH_MODE.NEURAL_PLUS     # 최고 정밀도 Neural Depth
COORDINATE_UNITS = sl.UNIT.MILLIMETER       # mm 단위

# 블러 필터링 임계값
BLUR_THRESHOLD = 100  # Laplacian 분산 < 100 → 블러 판정, 저장 제외
```

### 4.3 촬영 프로세스

1. `python 01_capture_dataset.py` 실행 후 브라우저에서 `http://0.0.0.0:5000` 접속
2. 웹 UI에서 대상 클래스 선택
3. ZED X Mini 카메라로 도어 부품을 다양한 각도/거리에서 촬영
4. 블러 필터링 통과 시 RGB + Depth 쌍으로 자동 저장
5. 촬영 완료 후 `metadata.json` 자동 업데이트

### 4.4 촬영 시 유의사항

| 항목 | 권장 사항 |
|------|----------|
| 촬영 거리 | 약 1.0m ~ 3.0m (부품 전체가 프레임에 포함) |
| 촬영 각도 | 정면, 좌/우 30~45°, 상/하 15~30° 다양하게 |
| 조명 조건 | 실내 조명 기본, 직사광선 회피 |
| 배경 | 작업장 바닥, 팔레트, 벽면 등 실제 현장 배경 |
| 부품 상태 | 도장/미도장, 녹, 오염 등 다양한 상태 포함 |

### 4.5 출력 파일 구조

각 클래스 폴더에 RGB-Depth-Mask 3파일이 동일 인덱스로 저장된다:

| 파일 | 형식 | 크기 | 설명 |
|------|------|------|------|
| `rgb_NNNN.png` | PNG 8bit RGB | 1920×1080 | RGB 이미지 |
| `depth_NNNN.png` | PNG 16bit Grayscale | 1920×1080 | Depth 맵 (mm 단위) |
| `mask_NNNN.png` | PNG 8bit Grayscale | 1920×1080 | SAM 전경 마스크 (0 or 255) |
| `metadata.json` | JSON | ~0.3KB | 클래스별 메타정보 |

## 6. 데이터 증강 명세

### 6.1 개요

데이터 증강은 **온라인 증강**(학습 시 실시간 적용)과 **오프라인 증강**(사전 데이터셋 생성) 두 가지 방식을 병행한다.

```
                    ┌──────────────────────────────┐
                    │     원본 데이터셋 (datasets/) │
                    └──────────┬───────────────────┘
                               │
              ┌────────────────┼────────────────┐
              ↓                ↓                ↓
     [온라인 증강]      [오프라인 증강 A]     [오프라인 증강 B]
     RGBDTransform      mask_only moderate    전체 moderate
     (학습 시 실시간)    → datasets_aug/       → datasets_aug2/
```

### 6.2 온라인 증강 (`RGBDTransform`)

**파일**: `depth_utils.py` 내 `RGBDTransform` 클래스

학습 시 DataLoader에서 매 에폭마다 다른 변환을 적용한다. RGB와 Depth에 동기화된 공간 변환을 수행하며, 색상/노이즈 변환은 RGB에만 적용한다.

#### 전처리 (학습/평가 공통)

| 단계 | 처리 | 설명 |
|------|------|------|
| Letterbox Resize | 장변 기준 448px 축소 | 종횡비 보존 |
| 중앙 패딩 | 검정(0) 패딩 | 448×448 정사각형 생성 |

#### 학습 시 증강 파라미터

| 증강 종류 | 적용 대상 | 파라미터 | 확률 |
|-----------|----------|----------|------|
| 수평 반전 | RGB + Depth | - | 50% |
| 회전 | RGB + Depth | ±15° | 100% |
| 스케일 | RGB + Depth | 90~110% | 50% |
| 밝기 조절 | RGB만 | 0.6~1.4 | 100% |
| 대비 조절 | RGB만 | 0.6~1.4 | 100% |
| 채도 조절 | RGB만 | 0.7~1.3 | 100% |
| 색조 변환 | RGB만 | ±0.05 | 100% |
| 가우시안 노이즈 | RGB만 | σ=3~10 | 30% |
| 가우시안 블러 | RGB만 | kernel=3 | 20% |

#### 정규화

| 채널 | 정규화 방식 |
|------|------------|
| RGB | ImageNet 표준: mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225] |
| Depth | (x - 0.5) / 0.25 |

### 6.3 오프라인 증강 (`06_generate_augmented_dataset.py`)

사전에 RGB 이미지를 증강하여 별도 데이터셋으로 저장한다. Depth와 Mask는 원본을 그대로 복사하므로 Aux 피처(물리 치수)는 보존된다.

#### 증강 강도 프리셋

| 파라미터 | mild | moderate | extreme |
|----------|------|----------|---------|
| Brightness | 0.5~1.5 | 0.5~1.8 | 0.2~3.0 |
| Contrast | 0.5~1.5 | 0.5~1.8 | 0.2~3.0 |
| Saturation | 0.3~1.7 | 0.2~2.0 | 0.0~3.0 |
| Hue Shift | ±30° | ±40° | ±90° |
| Noise σ | 10~25 | 15~30 | 30~60 |
| Blur kernel | 3~7 | 3~9 | 7~15 |

#### 증강 모드

| 모드 | `--mask_only` 플래그 | 설명 |
|------|---------------------|------|
| 전체 이미지 | 미지정 | RGB 전체 영역에 증강 적용 |
| 마스크 전용 | `--mask_only` | 전경(부품)만 증강, 배경은 원본 유지 |

**마스크 전용 증강 원리**: SAM 마스크를 기반으로 전경/배경을 분리한 후, 증강된 이미지의 전경 영역과 원본 이미지의 배경 영역을 알파 블렌딩으로 합성한다.

```python
# apply_mask_blend 핵심 로직
blended = original * (1.0 - mask) + augmented * mask
```

#### 증강 적용 순서

```
RGB 원본 → Brightness → Contrast → Saturation → Hue Shift
        → Gaussian Noise → Gaussian Blur → (mask blend) → 저장
```

### 7.4 보조 피처 (Auxiliary Features)

학습 시 Depth 맵에서 3D PCA를 통해 물리 치수를 실시간 계산하여 모델의 보조 입력으로 사용한다.

| 피처 | 단위 | 설명 |
|------|------|------|
| `physical_width_mm` | mm | PCA 1축 (장축) 범위 |
| `physical_height_mm` | mm | PCA 2축 (단축) 범위 |
| `aspect_ratio` | 무차원 | width / height |

**계산 과정**:
```
전경 픽셀 (mask/Otsu) → 깊이값으로 3D 점 변환 (pixel_to_3D)
→ 3D 점군 SVD 분해 → 주성분 2축 투영 → 가로/세로 범위 추출
```

### 7.5 학습 입력 텐서 형식

| 항목 | Shape | 설명 |
|------|-------|------|
| RGBD 텐서 | `[B, 4, 448, 448]` | Batch × (RGB+Depth) × Height × Width |
| Aux 피처 | `[B, 3]` | Batch × (width, height, aspect_ratio) |
| Label | `[B]` | Batch × class_index |

### 9.4 검증 스크립트 예시

```python
import os
import glob
import cv2
import numpy as np

def verify_dataset(dataset_dir):
    """실물 도어 데이터셋 품질 검증"""
    class_dirs = sorted([
        d for d in os.listdir(dataset_dir)
        if os.path.isdir(os.path.join(dataset_dir, d))
        and not d.startswith(".")
    ])

    for class_name in class_dirs:
        class_dir = os.path.join(dataset_dir, class_name)
        rgb_files = sorted(glob.glob(os.path.join(class_dir, "rgb_*.png")))
        depth_files = sorted(glob.glob(os.path.join(class_dir, "depth_*.png")))
        mask_files = sorted(glob.glob(os.path.join(class_dir, "mask_*.png")))

        print(f"\n{class_name}:")
        print(f"  RGB: {len(rgb_files)}장")
        print(f"  Depth: {len(depth_files)}장")
        print(f"  Mask: {len(mask_files)}장")

        # RGB-Depth 1:1 매칭 확인
        if len(rgb_files) != len(depth_files):
            print(f"  ⚠️ RGB-Depth 수 불일치!")

        # 첫 번째 이미지 품질 확인
        if rgb_files:
            img = cv2.imread(rgb_files[0])
            h, w = img.shape[:2]
            blur_score = cv2.Laplacian(
                cv2.cvtColor(img, cv2.COLOR_BGR2GRAY), cv2.CV_64F
            ).var()
            print(f"  해상도: {w}×{h}")
            print(f"  블러 점수: {blur_score:.1f}")

        if depth_files:
            depth = cv2.imread(depth_files[0], cv2.IMREAD_UNCHANGED)
            valid_ratio = (depth > 0).sum() / depth.size
            d_min = depth[depth > 0].min() if (depth > 0).any() else 0
            d_max = depth.max()
            print(f"  Depth 유효 비율: {valid_ratio*100:.1f}%")
            print(f"  Depth 범위: {d_min}mm ~ {d_max}mm")

        if mask_files:
            mask = cv2.imread(mask_files[0], cv2.IMREAD_GRAYSCALE)
            fg_ratio = (mask > 127).sum() / mask.size
            print(f"  전경 비율: {fg_ratio*100:.1f}%")

verify_dataset("datasets")
```

                           │                   └────────┬────────┘

                           │                   ┌─────────────────┐

                           │                   └────────┬────────┘

### C. 파일명 규칙

| 패턴 | 예시 | 설명 |
|------|------|------|
| `rgb_NNNN.png` | `rgb_0000.png` | 4자리 0-padded 인덱스 |
| `depth_NNNN.png` | `depth_0000.png` | RGB와 동일 인덱스 |
| `mask_NNNN.png` | `mask_0000.png` | RGB와 동일 인덱스 |

인덱스는 0부터 시작하며, 기존 이미지가 있을 경우 마지막 인덱스+1부터 자동 증가한다.

### D. 문제 해결

#### ZED 카메라 연결 실패
```
RuntimeError: ZED 카메라 초기화 실패
```
**해결**: ZED SDK 설치 확인, USB/GMSL2 연결 확인. pyzed 미설치 시 OpenCV 폴백(RGB only)으로 동작한다.

#### SAM2 마스크 생성 실패
```
전경 마스크가 생성되지 않음
```
**해결**: 부품이 이미지 중심에 위치하는지 확인. SAM2는 이미지 중심점을 positive 프롬프트로 사용하므로, 부품이 프레임 가장자리에 있으면 정확도가 떨어진다.

#### Depth 유효 비율 낮음
```
Depth 유효 비율: 60% 미만
```
**해결**: 촬영 거리 확인 (ZED X Mini 최적 범위: 0.3m~5m), 반사 표면이나 투명 재질 회피, Neural Depth 모드 사용 확인.
