## 1. 개요

### 1.1 시스템 소개

이 시스템은 굴착기 부품 이미지를 입력받아 **부품 종류를 자동으로 분류**하는 AI 모델입니다.

**지원 부품 클래스**:
- `arm_link_25_nomat` (암 링크 25톤)
- `arm_link_30_notmat` (암 링크 30톤)
- `boom_link_25_nomat` (붐 링크 25톤)
- `boom_link_30_notmat` (붐 링크 30톤)

### 1.2 시스템 구성

```
입력: 굴착기 부품 이미지 (PNG, JPG)
    ↓
전처리: 리사이즈 (224×224) + 정규화
    ↓
AI 모델: ResNet18 기반 분류기
    ↓
출력: 부품 클래스명 + 신뢰도(%)
```

### 1.3 성능 요약

| 지표 | 값 |
|------|-----|
| 전체 정확도 | 96.75% |
| 평균 F1-Score | 96.75% |
| 추론 속도 | ~10ms/이미지 (GPU) |

## 7. 모델 활용 (추론)

### 7.1 Python 코드로 추론

```python
import torch
import torch.nn as nn
from torchvision import transforms, models
from PIL import Image
import json

# 1. 모델 로드
def load_model(model_path, class_names_path, device='cuda'):
    # 클래스명 로드
    with open(class_names_path, 'r') as f:
        class_names = json.load(f)
    num_classes = len(class_names)
    
    # 모델 생성
    model = models.resnet18(pretrained=False)
    model.fc = nn.Sequential(
        nn.Dropout(0.5),
        nn.Linear(512, 256),
        nn.ReLU(),
        nn.Dropout(0.3),
        nn.Linear(256, num_classes)
    )
    
    # 가중치 로드
    model.load_state_dict(torch.load(model_path, map_location=device))
    model.to(device)
    model.eval()
    
    return model, class_names

# 2. 이미지 전처리
def preprocess_image(image_path):
    transform = transforms.Compose([
        transforms.Resize((224, 224)),
        transforms.ToTensor(),
        transforms.Normalize(mean=[0.485, 0.456, 0.406],
                            std=[0.229, 0.224, 0.225])
    ])
    
    image = Image.open(image_path).convert('RGB')
    return transform(image).unsqueeze(0)  # 배치 차원 추가

# 3. 추론
def predict(model, image_tensor, class_names, device='cuda'):
    image_tensor = image_tensor.to(device)
    
    with torch.no_grad():
        outputs = model(image_tensor)
        probabilities = torch.softmax(outputs, dim=1)
        confidence, predicted_idx = torch.max(probabilities, 1)
    
    return {
        'class': class_names[predicted_idx.item()],
        'confidence': confidence.item() * 100,
        'all_probs': {
            name: prob.item() * 100 
            for name, prob in zip(class_names, probabilities[0])
        }
    }

# 사용 예시
if __name__ == '__main__':
    # 경로 설정
    MODEL_PATH = 'class_estimation/artifacts/best_parts_model.pth'
    CLASS_NAMES_PATH = 'class_estimation/artifacts/class_names.json'
    TEST_IMAGE = 'test_image.png'
    
    # 디바이스 설정
    device = 'cuda' if torch.cuda.is_available() else 'cpu'
    
    # 모델 로드
    model, class_names = load_model(MODEL_PATH, CLASS_NAMES_PATH, device)
    
    # 이미지 전처리
    image_tensor = preprocess_image(TEST_IMAGE)
    
    # 추론
    result = predict(model, image_tensor, class_names, device)
    
    print(f"예측 클래스: {result['class']}")
    print(f"신뢰도: {result['confidence']:.2f}%")
    print("클래스별 확률:")
    for name, prob in result['all_probs'].items():
        print(f"  - {name}: {prob:.2f}%")
```

### 7.2 배치 추론 (여러 이미지)

```python
def batch_predict(model, image_paths, class_names, device='cuda', batch_size=32):
    """여러 이미지를 한 번에 추론"""
    results = []
    
    for i in range(0, len(image_paths), batch_size):
        batch_paths = image_paths[i:i+batch_size]
        batch_tensors = torch.cat([
            preprocess_image(p) for p in batch_paths
        ], dim=0).to(device)
        
        with torch.no_grad():
            outputs = model(batch_tensors)
            probs = torch.softmax(outputs, dim=1)
            confidences, predictions = torch.max(probs, 1)
        
        for j, path in enumerate(batch_paths):
            results.append({
                'path': path,
                'class': class_names[predictions[j].item()],
                'confidence': confidences[j].item() * 100
            })
    
    return results
```

## 8. 문제 해결

### 8.1 일반적인 오류

#### CUDA 메모리 부족
```
RuntimeError: CUDA out of memory
```
**해결 방법**:
- 배치 크기 줄이기: 코드에서 `BATCH_SIZE = 16` 또는 더 작게 설정
- CPU로 실행: `--cpu` 옵션 사용
- GPU 캐시 정리: `torch.cuda.empty_cache()`

#### 모델 파일 없음
```
FileNotFoundError: 모델 파일을 찾을 수 없습니다
```
**해결 방법**:
- 먼저 `02_parts_classification.py`를 실행하여 모델 학습
- 모델 경로 확인: `class_estimation/artifacts/best_parts_model.pth`

#### 데이터셋 없음
```
발견된 클래스: 0개
```
**해결 방법**:
- 데이터셋 경로 확인
- Isaac Sim에서 `01_generate_multi_class_dataset.py` 실행

### 8.2 성능 최적화

#### 학습 속도 향상
- `num_workers` 증가 (현재 0으로 설정됨)
- Mixed Precision Training 적용

#### 정확도 향상
- 데이터 증강 강화
- 에포크 수 증가
- Learning Rate 조정

## 9. FAQ

### Q1. 새로운 부품 클래스를 추가하려면?

1. USD 부품 모델을 `assets/` 폴더에 추가
2. `01_generate_multi_class_dataset.py` 실행 (자동으로 스캔)
3. `02_parts_classification.py` 재학습

### Q2. 실제 카메라 이미지로 추론하려면?

1. 이미지를 RGB 형식으로 변환
2. 조명/배경이 학습 데이터와 유사하게 조정
3. BBox 크롭 사용 권장 (배경 노이즈 제거)

### Q3. 모델을 다른 환경에 배포하려면?

1. 모델 파일 (`best_parts_model.pth`) 복사
2. 클래스 정보 (`class_names.json`) 복사
3. PyTorch 환경 설치
4. 위의 추론 코드 사용

### Q4. CPU와 GPU 성능 차이는?

| 환경 | 추론 시간 (이미지당) |
|------|---------------------|
| GPU (RTX 3060) | ~10ms |
| CPU (i7) | ~100ms |
