## 1. 개요

### 1.1 시스템 소개

이 시스템은 굴착기 부품의 **3D 위치와 자세(6DoF)**를 추정합니다.

**6DoF (6 Degrees of Freedom)**:
- **위치 (Translation)**: X, Y, Z (단위: 미터/밀리미터)
- **자세 (Rotation)**: Roll, Pitch, Yaw (단위: 도)

### 1.2 제공 모델

| 모델 | 입력 | 출력 | 스크립트 |
|------|------|------|----------|
| XY 위치 회귀 | RGB (BBox crop) | 작업대 X, Y | `04_parts_pos_estimation.py` |
| ICP 기반 | Depth | 3D 위치 | `05_icp_pose_estimation.py` |
| 딥러닝 6DoF | RGB + Depth | 6DoF Pose | `06_deep_6dof_estimation.py` |
| Depth GT 기반 | RGB (+ Depth GT) | 3D 위치 | `07_depth_based_pose.py` |

### 1.3 성능 목표

- **목표 정밀도**: 10mm (1cm) 이내
- **실시간 추론**: 30fps 이상 (GPU 환경)

## 3. 좌표계 정의

### 3.1 OpenCV/Depth 좌표계 (카메라 기준)

시스템은 **OpenCV/Depth 좌표계**를 사용합니다:

```
카메라 좌표계 (Camera Frame):

       Y (아래 +)
       |
       |
       +------→ X (오른쪽 +)
      /
     /
    Z (앞쪽 +, forward)
```

| 축 | 방향 | 설명 |
|----|------|------|
| X | 오른쪽 (+) | 카메라 기준 우측 |
| Y | 아래쪽 (+) | 카메라 기준 하단 |
| Z | 앞쪽 (+) | 카메라에서 물체 방향 |

### 3.2 회전 정의 (Euler Angles)

| 회전 | 축 | 설명 |
|------|-----|------|
| Roll | X축 | 카메라 시점에서 좌우 기울임 |
| Pitch | Y축 | 상하 기울임 |
| Yaw | Z축 | 좌우 회전 |

### 3.3 좌표 변환 (USD → OpenCV)

Isaac Sim(USD)은 **OpenGL 좌표계** (Y-up, -Z forward)를 사용합니다.  
데이터 생성 시 자동으로 **OpenCV 좌표계**로 변환됩니다:

```python
# USD (OpenGL) → OpenCV 변환
camTobj_opencv = np.array([
    camTobj_usd[0],    # X 유지
    -camTobj_usd[1],   # Y 반전
    -camTobj_usd[2]    # Z 반전
```

## 6. 모델 평가

### 6.1 평가 지표

| 지표 | 설명 | 단위 |
|------|------|------|
| Mean Position Error | 예측 위치와 GT 위치의 유클리드 거리 평균 | mm |
| X Error | X축 절대 오차 평균 | mm |
| Y Error | Y축 절대 오차 평균 | mm |
| Z Error | Z축 절대 오차 평균 | mm |
| Rotation Error | 회전 오차 (quaternion distance) | degrees |

### 6.2 평가 코드 예시

```python
def evaluate_mean_pos_error_mm(model, loader, xy_mean, xy_std, device):
    """위치 추정 오차 평가 (mm 단위)"""
    model.eval()
    errors_mm = []
    
    with torch.no_grad():
        for images, xy_norm in loader:
            images = images.to(device)
            xy_norm = xy_norm.to(device)
            
            # 예측
            pred_norm = model(images)
            
            # 역정규화 (미터 → 밀리미터)
            mean = torch.tensor(xy_mean, device=device).view(1, -1)
            std = torch.tensor(xy_std, device=device).view(1, -1)
            
            pred = pred_norm * std + mean
            gt = xy_norm * std + mean
            
            # 유클리드 거리 (미터 → 밀리미터)
            diff = pred - gt
            dist = torch.linalg.norm(diff, dim=1) * 1000.0  # mm
            errors_mm.extend(dist.cpu().numpy().tolist())
    
    return np.mean(errors_mm)
```

## 7. 추론 및 활용

### 7.1 XY 위치 추론

```python
import torch
import torch.nn as nn
from torchvision import transforms, models
from PIL import Image
import json
import numpy as np

class PartsXYRegressor:
    def __init__(self, model_path, stats_path, device='cuda'):
        self.device = device
        
        # 정규화 통계 로드
        with open(stats_path, 'r') as f:
            stats = json.load(f)
        self.xy_mean = np.array(stats['xy_mean'])
        self.xy_std = np.array(stats['xy_std'])
        
        # 모델 로드
        checkpoint = torch.load(model_path, map_location=device)
        self.model = models.resnet18(pretrained=False)
        self.model.fc = nn.Sequential(
            nn.Dropout(0.2),
            nn.Linear(512, 128),
            nn.ReLU(),
            nn.Linear(128, 2)
        )
        self.model.load_state_dict(checkpoint['model_state_dict'])
        self.model.to(device)
        self.model.eval()
        
        # 전처리
        self.transform = transforms.Compose([
            transforms.Resize((224, 224)),
            transforms.ToTensor(),
            transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])
        ])
    
    def predict(self, image_path, bbox=None):
        """
        이미지에서 XY 위치 예측
        
        Args:
            image_path: RGB 이미지 경로
            bbox: (x_min, y_min, x_max, y_max) - 선택적 크롭
        
        Returns:
            dict: {'x_m': float, 'y_m': float, 'x_mm': float, 'y_mm': float}
        """
        # 이미지 로드
        image = Image.open(image_path).convert('RGB')
        
        # BBox 크롭 (선택적)
        if bbox:
            image = image.crop(bbox)
        
        # 전처리
        image_tensor = self.transform(image).unsqueeze(0).to(self.device)
        
        # 추론
        with torch.no_grad():
            pred_norm = self.model(image_tensor)
        
        # 역정규화
        pred = pred_norm.cpu().numpy()[0]
        xy_m = pred * self.xy_std + self.xy_mean
        
        return {
            'x_m': float(xy_m[0]),
            'y_m': float(xy_m[1]),
            'x_mm': float(xy_m[0] * 1000),
            'y_mm': float(xy_m[1] * 1000)
        }

# 사용 예시
if __name__ == '__main__':
    regressor = PartsXYRegressor(
        model_path='pos_estimation/artifacts/best_parts_xy_regressor.pth',
        stats_path='pos_estimation/artifacts/xy_normalization_stats.json',
        device='cuda'
    )
    
    result = regressor.predict('test_image.png')
    print(f"예측 위치: X={result['x_mm']:.1f}mm, Y={result['y_mm']:.1f}mm")
```

### 7.2 6DoF 추론 (RGB + Depth)

```python
import torch
import numpy as np
from PIL import Image

class Deep6DoFEstimator:
    def __init__(self, model_path, device='cuda'):
        self.device = device
        
        # 모델 로드 (06_deep_6dof_estimation.py에서 정의된 모델 사용)
        checkpoint = torch.load(model_path, map_location=device)
        self.model = checkpoint['model']  # 또는 별도 모델 생성
        self.model.to(device)
        self.model.eval()
        
        self.position_stats = checkpoint.get('position_stats')
    
    def predict(self, rgb_path, depth_path):
        """
        RGB + Depth에서 6DoF 추정
        
        Returns:
            dict: {
                'position': [x, y, z] (meters),
                'rotation': [roll, pitch, yaw] (degrees)
            }
        """
        # RGB 로드 및 전처리
        rgb = Image.open(rgb_path).convert('RGB')
        rgb = self.rgb_transform(rgb).unsqueeze(0).to(self.device)
        
        # Depth 로드 및 전처리
        depth = np.load(depth_path)
        if len(depth.shape) == 3:
            depth = depth[:, :, 0]
        depth = self.preprocess_depth(depth).unsqueeze(0).to(self.device)
        
        # 추론
        with torch.no_grad():
            position, rotation_6d = self.model(rgb, depth)
        
        # 후처리 (역정규화, 6D→Euler 변환 등)
        position_m = self.denormalize_position(position.cpu().numpy()[0])
        euler_deg = self.rotation_6d_to_euler(rotation_6d.cpu().numpy()[0])
        
        return {
            'position': position_m.tolist(),
            'rotation': euler_deg.tolist(),
            'position_mm': (position_m * 1000).tolist()
        }
```

### 7.3 Depth에서 Point Cloud 생성

```python
def depth_to_pointcloud(depth, fx=768, fy=768, cx=512, cy=512):
    """
    Depth 이미지 → Point Cloud 변환
    
    Args:
        depth: (H, W) numpy array, 미터 단위
        fx, fy: focal lengths
        cx, cy: principal point
    
    Returns:
        points: (N, 3) numpy array [X, Y, Z]
    """
    h, w = depth.shape
    
    # 유효한 Depth 마스크
    valid_mask = (depth > 0.01) & (depth < 100.0) & np.isfinite(depth)
    
    # 픽셀 좌표 생성
    u = np.arange(w)
    v = np.arange(h)
    u, v = np.meshgrid(u, v)
    
    # 3D 좌표 계산
    z = depth
    x = (u - cx) * z / fx
    y = (v - cy) * z / fy
    
    # 유효한 점만 추출
    points = np.stack([
        x[valid_mask],
        y[valid_mask],
        z[valid_mask]
    ], axis=1)
    
    return points

# 사용 예시
depth = np.load('distance_to_camera_0000.npy')
if len(depth.shape) == 3:
    depth = depth[:, :, 0]

points = depth_to_pointcloud(depth)
print(f"Point Cloud: {len(points)} points")
print(f"범위: X=[{points[:,0].min():.2f}, {points[:,0].max():.2f}]m")
print(f"      Y=[{points[:,1].min():.2f}, {points[:,1].max():.2f}]m")
print(f"      Z=[{points[:,2].min():.2f}, {points[:,2].max():.2f}]m")
```

## 8. 문제 해결

### 8.1 일반적인 오류

#### 위치 추정 오차가 큼
**원인**: 좌표계 불일치 또는 정규화 문제

**해결 방법**:
1. `camTobj` (카메라 기준 상대 좌표) 사용 확인
2. 정규화 통계 (`xy_normalization_stats.json`) 확인
3. 역정규화 적용 확인

#### Depth 값이 비정상적
**원인**: `metersPerUnit` 스케일 문제

**해결 방법**:
```python
# 자동 스케일 보정 코드
if meters_per_unit_raw < 0.1:
    meters_per_unit = 1.0  # 보정
```

#### 모델 수렴 안함
**원인**: 학습률이 너무 높거나 데이터 불균형

**해결 방법**:
- 학습률 감소: `1e-4` → `5e-5`
- 에포크 증가: `50` → `150`
- 데이터 증강 강화

#### 추론 속도 향상
- 배치 처리 사용
- TorchScript 또는 ONNX 변환

- BBox 크롭으로 배경 노이즈 제거

### A. 6D Rotation Representation

신경망에서 회전을 학습할 때 **6D Rotation Representation**을 사용합니다:

```python
def rotation_6d_to_matrix(r6d):
    """6D → 3x3 회전 행렬"""
    a1 = r6d[:, :3]
    a2 = r6d[:, 3:6]
    
    # Gram-Schmidt 정규직교화
    b1 = F.normalize(a1, dim=1)
    b2 = a2 - (b1 * a2).sum(dim=1, keepdim=True) * b1
    b2 = F.normalize(b2, dim=1)
    b3 = torch.cross(b1, b2, dim=1)
    
    return torch.stack([b1, b2, b3], dim=2)
```

**참고 논문**: "On the Continuity of Rotation Representations in Neural Networks" (CVPR 2019)
