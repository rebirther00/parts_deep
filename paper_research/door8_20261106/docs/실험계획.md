# 8클래스 도어 분류 실험 계획 v1

작성일: 2026-11-06. 과거 현장 결과를 알고 설정한 후향적 재개발 계획이며, 사전등록된 독립 블라인드 연구가 아니다. 모델 선택과 숫자 공개를 구분하고 새 전향적 검증으로 보완한다.

## 연구 질문과 범위

주 질문은 “전체 전경·슬롯의 안정적인 분할이 어려운 촬영 조건에서, 소수 홀 랜드마크와 CAD 치수를 이용한 품종 식별이 현장 세션 변화에 얼마나 견디는가?”이다. 새로운 CNN 구조 발명이 아닌, 박판 도어에 적합한 표현의 선택과 측정 가능한 실패 조건을 평가한다.

H1: 홀 치수 방법이 RGB/RGBE 분류기보다 클래스 균형 성능과 세션 변화에 대한 안정성에서 이점이 있는지 확인한다. H2: 분할 기반 외형 치수 기준선과 비교해 홀 방법이 어떤 가림·배경 조건에서 실패를 줄이는지 확인한다. H3: 픽셀 스케일과 깊이 평면 방식의 치수 오차·커버리지 차이를 확인한다. 어느 가설도 현재 입증된 것으로 기술하지 않는다.

8클래스의 품종 구분만 주제로 한다. E23, 레이더 옵션 식별, VLM, 의사 좌표 생성 및 오라벨 정정 효과는 방법과 결과에 포함하지 않는다. 레이더 옵션의 육안 검증이 잘못되었다는 의미는 아니며, 이번 논문의 주장 범위를 집중하기 위한 결정이다.

## 데이터 포함 규칙

원본 작업자 품종 라벨과 현재 라벨이 같은 유효 현장 세션을 포함한다. 사용자가 불일치 사례를 전수 육안 확인하여 오라벨로 확정한 세션은 정정 라벨로 재사용하지 않고 전체를 제외한다. 기존 무효/부분 무효 세션도 제외한다. 선택된 모델의 성능이 낮다는 이유로 세션을 사후 제외하지 않는다.

세션당 최대 20프레임은 로컬 미러에 존재하는 영상의 파일 순서에서 균등 간격으로 추출한다. 원 수집 전 프레임을 이용한 결과라고 표현하지 않는다. 원본을 바꾸는 대신 이미지/깊이/수동 라벨 해시와 DB 복사본을 고정한다. 정확히 동일한 RGB가 서로 다른 세션에서 발견되면 같은 그룹으로 묶고, 라벨이 다르면 자동 선택 없이 중단한다. v1에는 세션 간 정확 중복 결합이 없었다. 근접 중복이나 동일 실물 재촬영까지 검사했다는 뜻은 아니다.

보조 홀 좌표는 실험실의 사람 수동 라벨 118장만 허용한다. 과거 현장 좌표 16장, 자동 교사 모델 좌표, 브래킷 규칙 좌표는 제외한다. 실험실 94/24 분할은 체크포인트 선택용이며 실험실 일반화 성능을 주장하는 시험이 아니다. 현장 클래스 라벨은 CNN 학습과 홀 스케일/마스크 중심 보정에 쓰인다. 따라서 “현장 데이터가 전혀 필요 없는 방법”이라는 주장은 금지한다.

## 교차검증과 모델 선택

| 단계 | 규칙 |
|---|---|
| 외부 반복 | 5폴드, 시드 42/123/456. 모든 방법의 현장 분할과 평가 프레임 일치 |
| 각 폴드 | 시험 k, 검증 (k+1)%5, 학습 나머지 3폴드 |
| CNN | 새 ImageNet ResNet18에서 학습; 검증 세션 balanced accuracy 최대 체크포인트, 동률이면 검증 loss 최소 |
| 홀 검출기 | 현장 영상 학습 없이 실험실 수동 좌표로 재학습; 실험실 검증 loss 최소; 시드별 한 모델을 현장 5폴드에 공통 사용 가능 |
| 홀 보정 | 해당 폴드 학습 세션만 사용; 카메라별 세션 중앙값의 중앙값으로 스케일 추정 |
| 마스크 기준선 | 해당 폴드 학습 세션의 치수 특징으로 클래스별 중심 및 표준화 척도 추정 |
| 판정 보류 | 홀 거리 허용값 30 mm 등은 과거 개발에서 정한 설정으로 공개. CNN은 보류 없는 결과와 검증 95% 커버리지 임계값 결과 병기 |
| 시험 결과 공개 | 정식 모델 학습 및 보정이 끝난 뒤 한 번 평가. 이후 수정은 새 실험 버전으로 남기며 독립 시험으로 재명명하지 않음 |

CNN은 448×448, 배치 32, 최대 40 epoch, Adam lr 0.0003, early stopping patience 8이다. 두 모델 모두 회전 ±8°, 스케일 0.9~1.1, 밝기·대비와 약한 블러를 사용한다. 좌우 품종 의미가 바뀔 수 있어 수평 반전을 사용하지 않는다. RGBE는 RGB와 같은 입력에 Canny(80,200) 엣지 1채널을 추가한다. 손실 가중치는 학습 클래스 빈도 제곱근 역비례다.

홀 모델은 ResNet18 기반 3채널 히트맵 복원 모델이다. 입력 1280×768, 출력 stride 4, 배치 4, 80 epoch, AdamW lr 0.0001, Gaussian sigma 2 heatmap px. 실험실 학습 영상에 회전·스케일·반전·밝기·블러를 적용한다. 가려지거나 누락된 점을 배경 정답으로 간주하지 않고 해당 채널의 감독을 마스킹한다. 테스트에서 현장 점 위치 정확도는 별도 수동 좌표가 없으면 주장하지 않는다.

## 비교 및 제거 실험

| 실험 | 구현 상태 | 해석 |
|---|---|---|
| RGB ResNet18 | 구현·소규모 GPU 검증 | 외관 분류 기준선 |
| RGBE ResNet18 | 구현·소규모 GPU 검증 | 기존 입력 표현 아이디어 재검증 |
| MobileSAM + 외형 치수 | 구현·소규모 추론 검증 | 전체 마스크에 의존하는 단순 기하 기준선 |
| 홀 + 픽셀 스케일 | 구현·소규모 추론 검증 | 학습 세션 기반 카메라 스케일 |
| 홀 + 깊이 평면 | 구현·소규모 추론 검증 | 평면 내 거리와 보정 스케일 |
| 기하 gate 제거 | `eval-geometry --no-gates` | 검출·보정은 같게 두고 시험 시 기하 거절 효과만 비교 |
| 자세 gate 추가 | `eval-geometry --pose` | 깊이 1400~1500 mm, 기울기 ≤15°. 실패도 보류로 계산 |
| 현장 좌표 추가 | 주석 대기열만 생성 | 후속 0/소량 현장 감독 제거 실험. 실제 주석 전 결과 없음 |
| 현장 전향적 운영 | 기록 양식 생성 | 새로운 사람 확인 정답과 배포 모델 버전으로 별도 평가 |

분할 기준선의 프롬프트는 영상 비율 (0.08,0.05,0.92,0.95) 고정 박스이다. GT 박스나 정답 클래스별 프롬프트를 쓰지 않는다. 공개 MobileSAM 가중치로 마스크를 추정하고 모델 점수 및 최소 면적 3%로 선택한다. 정규화 카메라 좌표에서 최소 면적 사각형 장·단변 로그, 종횡비 로그, 채움 비율로 분류한다. 분할 IoU 정답은 현재 없으므로 IoU를 산출했다고 쓰지 않는다. 이 단순 기준선보다 우수하더라도 모든 분할 알고리즘보다 우수하다고 확대 해석할 수 없다.

홀 픽셀 방식은 D = S_camera × ||p_h-p_l||/fx, 깊이 방식은 D = K_camera × ||P_h-P_l||을 사용한다. CAD D와 측정 원값의 비를 학습 세션별로 중앙값 집계한 뒤 카메라별 중앙값으로 보정한다. 운영 코드의 전역 보정계수는 가져오지 않는다. 알려지지 않은 카메라는 기존 카메라 스케일을 조용히 대입하지 않고 보류한다.

## 평가 지표와 통계

주 지표는 세션 및 프레임 macro-F1, balanced accuracy, 전체 정확도이며 클래스별 recall과 혼동행렬을 함께 제시한다. 실패·보류는 오답으로 전체 정확도 및 recall 분모에 남긴다. 커버리지와 수락된 결과만의 정확도도 함께 제시하되 후자만으로 우수성을 주장하지 않는다. 세션 결과는 수락된 프레임 예측의 최빈값이며 동률/전부 보류는 보류다. 따라서 프레임 커버리지도 반드시 병기한다. 최대 20프레임의 세션 다수결은 오프라인 요약이며, 한 프레임 실시간 성능이나 세션 확정 지연을 뜻하지 않는다.

시드마다 5개 시험 폴드의 OOF 예측을 한 번씩만 합친다. 시드 반복의 표본 수를 세 배로 계산하지 않는다. 방법 간 비교는 같은 세션 예측끼리 대응시키고 그룹 bootstrap 2,000회로 세션 정확도 차이의 95% 구간을 계산한다. McNemar 정확 검정은 세션 독립성 가정 아래 보조 지표로 쓴다. 여러 비교의 탐색적 p값을 단일 확증 검정처럼 제시하지 않는다. 현재 코드는 요청된 전체 방법 쌍에 대해 원 p값과 Holm 보정 p값을 함께 저장한다. 주 비교를 명시하고 독립성의 한계를 같이 기술한다.

세션 단위 Wilson 구간도 제공하지만 동일 실물이 여러 세션에 등장했을 가능성 때문에 독립 개체 시험의 신뢰구간으로 해석하지 않는다. 가능하면 추가 수집에서 물리적 개체 ID/생산 로트 ID를 기록하고 이 그룹으로 재분할한다. E25 LH FRT 9세션의 불확실성을 전체 정확도에 감추지 않는다.

치수 오차는 클래스 CAD 값에 대한 절대 오차·중앙값·95백분위수를 세션 단위로 제시한다. 이는 실물 치수 측정 정답에 대한 계측 정확도와 다르므로 “CAD 기준 잔차”라고 부른다. 최종 계측 오차 주장을 하려면 실측 치수와 공차가 필요하다. 국소화 오류·평면 실패·보정 오차·클래스 경계 오류를 구분해 실패 사례를 분석한다.

지연시간은 같은 GPU에서 단일 영상, 워밍업 후 CUDA 동기화, 전처리+추론+후처리 포함으로 측정한다. 현재 특징 추출 시간은 디스크 디코딩 제외이며 카메라/네트워크/API/대시보드 시간을 포함하지 않는다. 별도 end-to-end 측정 전에는 이 수치를 실시간 운영 지연이라고 쓰지 않는다. 소규모 8프레임 시간은 동작 검증이며 논문 지연 결과가 아니다.

## 후속 현장 수동 좌표와 전향적 시험

`field_annotation_queue.jsonl`은 세션당 2장, 총 722장의 빈 좌표 대기열이다. 값이 null인 파일은 정답 라벨이 아니다. 후속 실험에서는 해당 폴드의 학습 그룹만 주석 학습에 사용한다. 시험 그룹의 수동 좌표는 국소화 평가에만 쓰며 학습·임계값 선택에 쓰지 않는다. 전체 세션의 좌표를 한 번 학습한 모델로 교차검증하면 누수가 생긴다.

전향적 수집에는 `data/prospective/ground_truth_template.csv`를 사용한다. 모델 sha256, 코드/프로토콜 버전, 촬영 시각, 세션·개체·로트, 예측 및 보류 사유, 사람이 확인한 독립 품종과 확인 시각을 남긴다. 모든 대상의 정답을 확인하고 모델 불일치 사례만 평가하지 않는다. 가능하면 도면/작업 지시서 등 모델 외 근거로 확인하고, 예측을 보고 정답을 확인했다면 그 절차를 그대로 기술한다. 모델을 바꾸면 새 평가 구간을 시작한다. 아직 수집하지 않은 건수나 정확도는 초안에 채우지 않는다.
