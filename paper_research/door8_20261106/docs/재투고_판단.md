# 재투고 가능성에 대한 현재 판단

작성일: 2026-11-06. 이 문서는 게재 가능성을 보장하는 평가서가 아니라, 현재 자료와 구현으로 주장할 수 있는 범위를 정리한 내부 판단이다.

**논문으로 발전시킬 만한 문제·방법·현장 자료는 있다. 다만 지금은 제출 가능한 결과 논문이 완성된 상태가 아니다.** 실험실 수동 홀 라벨로 검출기를 재학습하고, 현장에서는 학습 세션으로만 치수를 보정한 뒤 분리된 세션에서 검증하는 구성이 주 실험으로 적절하다. 현장 홀 좌표를 대량으로 새로 표시하는 방식은 성능 개선에는 유용할 수 있으나, 먼저 수행하면 현장 감독이 적은 조건에서 작동한다는 장점을 평가하기 어려워진다. 소량 현장 좌표 추가는 후속 제거 실험으로 두는 편이 의미가 크다.

이 선택이 홀 방법에 유리한 정보만 준 비교로 보이지 않도록 감독 정보를 공개해야 한다. 홀 방법은 실험실의 수동 점 좌표와 CAD 치수를 사용하고, CNN은 현장 품종 라벨을 사용한다. 현장 클래스 라벨은 홀 치수 보정에도 쓰인다. 그러므로 “동일 감독 조건의 순수 알고리즘 비교”나 “현장 데이터 없이 일반화”라고 쓸 수는 없다.

## 기존 심사 의견에 대한 변화

근거: `class_estimation/door_paper/답변서.txt` 및 기존 원고·심사의견 검토. 기존 답변서의 핵심은 RGBE 채널 추가의 차별성 부족, 데이터 규모·다양성에 따른 일반화 의문, 구성과 표현 문제였다.

| 기존 우려 | 이번 방향 | 아직 필요한 증거 |
|---|---|---|
| 채널 하나 추가한 것이 기여인가 | 전체 외관 분류와 홀 기반 치수 판정의 문제 표현을 비교 | 새 분할에서의 공정한 정량 비교, 치수 오차 및 실패 원인 |
| 작은/제한된 데이터에만 맞는가 | 361세션 8클래스, 세션 단위 CV와 시간 분할 | 희소 클래스 추가 수집, 동일 실물/로트 추적, 향후 고정 모델 시험 |
| 결과를 보고 조건을 고른 것은 아닌가 | 과거 관찰 기간임을 명시하고 각 폴드에서 재학습·재보정 | 향후 전향적 자료로 최종 주장을 보완 |
| 논문 구조가 산만함 | 문제 → 관련연구 → 방법 → 동일 조건 평가 → 한계 | 결과에 맞춰 초록·논의·결론 재작성 |
| 표·인용·영문/수치 형식 부적절 | 표와 그림의 역할을 미리 고정하고 출처 확인 | 투고 학술지 확정 후 해당 양식 최종 편집 |

## 차별성을 과장하면 안 되는 이유

Behnen 등은 판금의 코너를 학습 기반 특징점으로 검출하여 실제 생산 영상에서 평가했다. 특징점 검출을 판금에 적용한다는 것만으로 최초성이 성립하지 않는다. 본 연구의 가능한 차별점은 도어 외곽이 아닌 내부 가공 홀의 상대 기하와 CAD 품종 치수로 **유사 품종을 식별**하고, 생산 현장의 세션 변화에서 외관·분할 방식과 비교한다는 점이다. [논문 원문](https://link.springer.com/article/10.1007/s10845-024-02552-7)

Prünte 등의 유사 엔진 튜브 식별 연구도 이미지·기하·점군 표현을 비교했다. 따라서 “CNN과 기하를 비교했다”는 주장만으로도 부족하다. 도어에서 어떤 치수가 품종 간 구별력을 가지는지, 최소 치수 차이 41 mm에 비해 잔차가 어느 수준인지, 보류가 실제 위험을 줄이는지를 밝혀야 한다. [논문 및 초록](https://pubmed.ncbi.nlm.nih.gov/37571562/)

## 재거절 위험이 큰 상태

1. 과거 99~100% 성능을 새 독립 시험처럼 제시하는 경우. 이전 자료를 재분할해도 과거 설계 판단에서 사용한 사실은 사라지지 않는다.
2. 홀 방법의 보류를 제외한 정확도와 CNN의 전체 정확도를 비교하는 경우. 보류 포함 정확도와 커버리지를 같이 내야 한다.
3. 실험실 118장 및 CAD라는 추가 감독 정보를 숨기거나, 약한 분할 기준선만 이겨 분할 전체보다 우수하다고 주장하는 경우.
4. 박판이라는 현장 설명만으로 분할 실패의 원인을 단정하는 경우. 실측 두께, 관측 조건, 실제 실패 사례와 대조가 필요하다.
5. 프레임 7,104장을 독립 표본으로 간주해 통계적 유의성을 과장하는 경우. 동일 세션 내 연속 영상은 강하게 상관될 수 있다.
6. 9세션뿐인 E25 LH FRT의 불확실성을 전체 평균에 묻거나 물리적 개체 독립성이 확인됐다고 쓰는 경우.

## 제출 전 최소 완료 항목

- 새 5폴드 × 3시드 학습·평가, 동일 입력의 OOF 비교, 보류 포함 성능, 클래스별 지지 수.
- 홀 픽셀/깊이 비교와 기하 거절 제거 실험. CNN 대비 이점이 없으면 결론도 그대로 수정.
- 분할 실패와 홀 실패를 모두 보여주는 현장 사례 및 CAD 기준 잔차 분석.
- 고정된 모델로 새로 수집한 현장 자료의 사람 확인 정답과 평가 기간. 최소 필요 건수를 무근거로 정하지 않고 클래스별 표본과 신뢰구간 폭으로 판단.
- 장비·조명·거리·공칭 1.2 mm의 실물 편차·실물/로트 추적 가능성·주석 비용 확인, 같은 하드웨어의 전체 추론 시간 측정.

현재의 작업은 이 항목을 수행할 수 있는 격리된 재현 환경과 초안을 만든 것이다. 논문이 된다는 판단은 “홀 검출기를 만들었다”는 사실보다, 위 질문에 검증 가능한 결과로 답할 수 있느냐에 달려 있다.
