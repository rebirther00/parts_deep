## 2. 추가 분석

프로토콜 하나를 계산 전에 등록했다.

| 프로토콜 | 등록(11/13) | 내용 |

- **큐.** 09:49:41~12:15:04, 50단계 모두 성공, 재실행 없음.
- **재현.** 16개 모두에서 재학습의 손실·검증 정확도가 저장된 기록과 epoch마다 같았고, "규칙" 체크포인트의 가중치는 저장된 가중치와 모든 텐서가 같았다. 이 PC에서 학습은 결정적이다.
- **결과.** 마할라노비스 점수의 미등록 도어 보류(73개 중): 저장값 52 / 66, 규칙 52 / 66, 마지막 52 / 70(RGB / RGBE). 문안 규칙 (a).
- **규칙 밖의 관찰.** 합계는 비슷하나 구성이 바뀌었다. RGB에서 E30 LH FRT 8→3개, E38 LH FRT 0→4개, E30/E38 RH 0→1개. RGBE에서 E30 LH FRT 8→9개, E38 LH FRT 0→3개. 원고 4.4절에 RGB의 변화를 적었다.
- **이른 선택의 원인.** 16개 중 12개는 선택 epoch와 40 epoch의 검증 정확도가 같았다. 동률일 때 검증 손실이 낮은 쪽을 고르는 규칙 때문에 이른 epoch가 선택된 것이다.
- **마지막 체크포인트의 다른 값.** 출력 기반 세 점수의 보류는 38개(RGB), 27~38개(RGBE)로 조금 늘었다. 보류 없이 본 등록 도어 정확도는 두 CNN 모두 511 / 511.

실행 기록에 남긴 사항(`reports/extension_v17/run_notes.json`):

- **미리 본 값.** 등록 전에 v16 결과에서 선택 epoch와 마할라노비스 보류 수의 표를 보았다(등록 파일에 기록). v17의 출력은 등록 전에 없었다.
- **시험 실행.** 큐 전에 2 epoch짜리 시험 실행을 임시 이름으로 두 번 했다. 학습·검증 자료만 읽었고 폴더는 큐 전에 지웠다.
- **기술적 재실행.** 없음.

계획표 대조와 임계값 역전의 확인은 이미 있는 결과 파일(`reports/extension_v16/production_plan_check.json`, `c2_operating_points.json`)을 읽은 것이다. 새 계산이 아니다.

## 3. v16에서 바뀐 곳

- **초록.** 기준선 수치에 "(286 with the learned scale)" 추가, 마지막 문장 정리. 150단어.
- **서론.** "저자의 영상 확인에서 … 다르다고 판단한 세션이 11개(3.0%)였다(3.1절)".
- **3.1절.** "판단" 표현 두 곳. 제외한 5세션의 계획표 대조. 제2 판독의 방법과 결과. "제2 확인자의 판독은 없다" 삭제.
- **3.2절.** 기준선 문단을 다시 씀(템플릿·LoG·외곽 폭의 설정값, 폭의 mm 환산식, 실패 처리 규칙, S를 기준선 자신의 검출로 다시 구했다는 것).
- **3.3절.** 공통 학습 조건 문단 축약. "시험 도어에 적용하였다".
- **3.4절.** "신경망 학습을 쓰지 않는", 제2 판독과 체크포인트 민감도 분석의 추가 시점.
- **4.2절, Table 3.** 사후 진단 행(*), 190·286·361개의 차이가 어디서 오는지, 진단의 성격.

## 5. 저자가 확인할 것

1. **가림 판독의 기록.** 원고의 "23개 모두 일치"는 교신저자가 전달한 결과를 적은 것이다. 답안 파일은 저장소에 없고 채점 스크립트(`scripts/make_blind_reading_kit_v16.py score <답안.csv>`)도 돌리지 않았다. 답안지를 보관하고, 가능하면 `reports/blind_reading_v16/`에 넣어 채점 기록을 남긴다. 아래 세 가지가 원고 문장과 맞는지도 확인한다.
   - 판독자가 라벨 확인(영상 확인)에 참여하지 않은 공저자이다.
   - 판독자가 받은 것은 `kit.zip`뿐이다(작업자 입력, 측정 D, 모델 출력, 세션 일자를 보지 않았다).
   - "판독 불가"나 "불명확"으로 답한 문항이 없다. 있으면 3.1절 문장을 고쳐야 한다.
2. **초록의 기준선 표현.** 6차 검토의 권고("at most 286 and 285")와 다르게 "190 (286 with the learned scale) and 285"로 썼다. 286개가 학습 검출기의 축척을 빌린 값이기 때문이다. 권고대로 바꾸려면 알려 주면 된다.
3. **체크포인트 분석의 범위.** 폴드 1만 다시 학습했다. 합계는 비슷했으나 수락되는 도어의 구성은 달라졌고, 원고에 그대로 적었다. 전 폴드로 늘려 달라는 요구가 나오면 CNN 64개를 더 학습해야 한다(이번 16개가 2시간 26분 걸렸으므로 약 10시간).
4. **분량 12쪽.** v16과 같다. 게재료는 9쪽부터 쪽당 3만 원이므로 12쪽이면 12만 원이다. 저자본은 LibreOffice 근사본에서 본문 마지막 쪽의 여유가 두 줄 정도여서, 한글 배치에서 13쪽으로 넘어갈 수 있다. 넘어가면 표·그림 위치로 조정한다.
5. **표 번호.** Table 5(공통 학습 조건)를 없애 뒤의 두 표 번호가 하나씩 당겨졌다. 한글에서 배치할 때 본문 참조(Table 5, Table 6)를 확인한다.
6. **현장 장치의 SDK·펌웨어.** 이전과 같다(9월 23일 무렵 갱신 여부의 기록 없음).
7. **저자 직위, 사사 과제번호 형식, 추계학술대회 포스터 인용 여부, 참고문헌 [6]·[7] 쪽수.** 이전과 같다.
