# 논문초안 v20 — 기종명과 날짜의 익명 표기

작성일: 2026-11-13. v19에서 기종명과 날짜의 표기만 바꾼 판이다. 교신저자의 결정으로, 같은 라인을 다룬 이진호 논문(`한국생산제조공학회논문_이진호_v3.2.pdf`)과 같은 표기를 썼다. 결과 수치, 도어 수, 치수, 결론은 바꾸지 않았다. v19 파일과 검토 문서는 수정하지 않았다.

이 문서에는 실제 기종과의 대응표가 들어 있다. 투고 자료에 넣지 않는다.

## 1. 대응표

## 2. 바뀐 곳

- **서론.** "기종(E25·E30·E38)과 위치" → "기종과 위치".
- **2.1절.** 표기 규칙을 넣었다. "기종군은 도어 크기 순서에 따라 A~D로 적고(대상은 B, C, D), 형상군은 위치(좌측 앞 FRT, 좌측 뒤 REAR, 우측 RH)와 기종군을 조합하여 FRT-B와 같이 표기한다. 기종군 C와 D의 우측 도어는 같은 형상이므로 한 형상군(RH-C/D)으로 묶었다."
- **3.1절.** 수집 기간과 날짜 표기 규칙("이하 날짜는 수집 첫날을 1일째로 하여 적는다"). 대상 밖 형상군의 소개("기종군 A의 좌측 앞 도어(FRT-A)"). "E25 기종이 계획된 날" → "기종군 B가 계획된 날".
- **본문 전체.** 기종명 76곳, 날짜 11곳. 이름이 바뀌면서 조사 4곳을 고쳤다("REAR-D(±2.22%)가", "REAR-D(29개)와", "FRT-A로", "FRT-A(6개)는").
- **Table 1, Table 5.** 행 이름. Table 5 캡션의 "E23:" → "FRT-A:".
- **Fig. 1.** 여덟 사진 위의 이름. 캡션 "Rows: LH front (FRT), LH rear (REAR), and RH doors".
- **Fig. 2.** (a)의 제목 "(FRT-D)". 캡션 "an FRT-D door".
- **Fig. 3.** 가로축의 이름.
- **배치.** 2.1절이 세 줄 늘어 Fig. 2를 2.2절 첫 문단 뒤로, Table 4를 4.3절 첫 문단 뒤로, Fig. 3을 "픽셀 폭 방식의 잔차는" 문단 뒤로, Table 6을 4.4절 FRT-A 문단 뒤로 옮겼다.

그림은 새 파일로 만들었다(`figures/v20c_fig_classes`, `v20c_fig2_method`, `v20c_fig3_relative_error`. 스크립트는 `scripts/make_figure_classes_v20.py`, `make_figure2_v20col.py`, `make_figure3_v20col.py`). 사진, 자르는 영역, 데이터, 그리는 방법은 이전 그림과 같고 글자만 다르다. Fig. 1과 Fig. 2는 이전 그림과 화소를 비교해 제목 줄만 달라진 것을 확인했다.

## 3. 바꾸지 않은 것

- **치수.** CAD 거리 D(Table 1, Fig. 1, Fig. 3, 본문), 볼트 배열 157×96 mm, Ø6은 그대로이다. 절댓값까지 감추는 것은 하지 않기로 했다.
- **도어 수와 세션 수.** 표본 크기이므로 그대로이다. 이진호 논문도 세션 수를 공개한다.
- **사진의 배경.** 흐리게 하지 않았다. Fig. 1과 Fig. 2는 도어와 지그 작업대만 보이게 자른 사진이고 공장 내부나 글자가 보이지 않는다. 3.1절의 라벨 확인과 제2 판독이 지그와 레일을 단서로 썼다고 적었으므로 지그가 보이는 편이 본문과 맞는다.
- **장치 이름.** 카메라(ZED X Mini)와 임베디드 장치(Jetson Orin NX)는 그대로이다. 이진호 논문도 카메라 이름을 적는다.
- **사업장.** 원래 "한 사업장"으로만 적혀 있다.

## 4. 확인한 것

- 원고(md), PDF 두 판, HWPX 두 판, DOCX 두 판에 E23·E25·E30·E38, "○월 ○일", "2026년"이 남아 있지 않다.
- v19와 v20의 본문에서 숫자를 모두 뽑아 비교했다. 달라진 것은 기종명의 숫자, 날짜, 그림 파일 이름뿐이다.
- 날짜 환산은 계산으로 확인했다(8월 27일 = 1일째, 10월 29일 = 64일째). 시간 분할은 10월 2일까지 228세션, 10월 3일부터 133세션이어서 "37일째까지 / 38일째부터"로 적었다.
- PDF는 두 판 모두 13쪽이고 글자 대조 검사를 통과했다. HWPX 두 개는 구조 검증을 통과했다. 익명본에는 저자·소속·과제번호·전자우편이 없다. 초록은 150단어 그대로이다.
- v20은 커밋하지 않았다.

## 5. 저자가 확인할 것

1. **이진호 논문과의 정합.** 두 논문이 같은 표기(A~D, FRT·REAR·RH)를 쓰게 되었다. 용어는 다르다(이진호 논문은 "품종", 본 원고는 "형상군"). 같은 호에 실릴 가능성이 있으면 서로 인용할지, 용어를 맞출지 정한다.
2. **카메라 설치 상태의 변화 시점.** 본 원고는 "26일째"로, 이진호 논문은 "수집 시작 약 6주 뒤"로 적는다. 두 논문의 수집 시작일이 달라 생기는 차이이다. 한쪽을 읽은 독자가 헷갈리지 않도록 이진호 논문 쪽 기간(약 11주)과 본 원고의 기간(약 9주)이 다른 이유를 공저자끼리 확인해 둔다.
3. **치수.** 협력업체가 CAD 거리의 공개도 꺼리면 다시 알려 준다. 절댓값을 감추려면 판정 여유와 잔차의 표기(%와 mm)를 함께 바꿔야 해서 별도의 수정이 된다.
4. **v19 작성확인사항의 게재료.** v17~v19 작성확인사항에 적은 "12만 원", "15만 원"은 9쪽부터의 초과분만 적은 것이다. 투고요령의 게재료는 1~8쪽 20만 원에 9쪽부터 쪽당 3만 원을 더하므로 13쪽이면 35만 원이다(11월 13일에 학회 페이지에서 확인. 한글이 깨져 영문 병기로 읽었으므로 투고 때 다시 확인한다).
5. **이전과 같은 항목.** 한글 최종 배치, 저자 직위, 사사 과제번호 형식, 추계학술대회 포스터 인용 여부, 참고문헌 [6]·[7] 쪽수, 판독 답안지 보관.
