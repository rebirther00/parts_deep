**3.4 Table 7 배치의 처리 근거.**
- 리뷰어가 본 것은 LibreOffice 근사본이다. 그런데 HWPX 정본의 본문 표 8개도 모두 `pageBreak="CELL"`(셀 단위로 나눔), `repeatHeader="0"`으로 생성되어 있어, 한글에서도 단 사이에서 나뉠 수 있었다.
- HWPX는 다음과 같이 고쳤다.
  - 본문 표 8개를 `pageBreak="NONE"`(나누지 않음)으로 바꾸었다.
  - 표 캡션 8개에 keepWithNext=1인 문단 모양(캡션 모양 id 5의 복제, id 53)을 지정하였다.
- docx는 표의 마지막 행을 뺀 모든 행에 keep-with-next를 지정하였다. 캡션은 이미 keep-with-next였다.
- 결과는 다음과 같다.
  - LibreOffice PDF에서 Table 1~8은 모두 한 단 안에 놓였다. Table 7은 10쪽 오른쪽 단, Table 8은 11쪽 왼쪽 단이다.
  - 표가 다음 단으로 넘어가면서 빈 공간이 생겨 PDF가 13쪽에서 14쪽이 되었다.
  - 한글에서 실제 쪽수와 빈 공간은 다를 수 있다.
