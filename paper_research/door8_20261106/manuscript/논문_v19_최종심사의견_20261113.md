# 논문 v19 최종 심사 의견

- 검토일: 2026년 11월 13일
- 대상: 「고정 지그 환경에서 홀 랜드마크와 CAD 치수 대조를 이용한 굴착기 도어 형상군 식별」, 논문초안_v19.hwpx
- 대조 자료: v18 원고와 논문_v18_심사의견_20261113.md
- 범위: 연구 내용과 게재 적합성. 저자 정보와 투고 서식은 제외하였다.
- 확인 수준: 버전 간 변경 사항, 본문·초록·표·결론의 일관성과 주요 수치의 산술을 검토했다. 원자료와 코드를 받아 실험을 재현한 것은 아니다.

## 1. 최종 판단

**내용 심사 기준으로 게재 가능을 권고한다. 이번 검토 범위에서 추가 필수 수정이나 필수 추가 실험은 없다. 현재 v19로 투고를 진행할 수 있다.**

v18에서 남긴 두 필수 수정 사항이 모두 반영되었다. 새로 추가한 템플릿 정합의 미등록 형상군 실험에서도 게재 판단을 뒤집을 새로운 핵심 오류는 발견하지 못했다. 따라서 이전의 “경미한 수정 후 게재 가능”에서 수정 조건이 충족된 것으로 판단한다.

이 권고는 고정 지그의 한 생산 현장에서 수행한 후향적 응용·실증 연구라는 현재 범위를 기준으로 한다. 새로운 범용 인식 알고리즘이나 모든 현장에서의 성능 우월성을 입증했다는 뜻은 아니다. 실제 학술지의 게재 결정과 구별되는 검토자의 내용 심사 의견이다.

## 2. v18의 필수 수정 사항은 완료되었는가

| 항목 | v19 확인 내용 | 처리 |
| --- | --- | --- |
| 356/361을 간격 조건만의 효과로 설명한 부분 | 초록은 “separation and selection fixes”, 본문은 간격 조건과 검증 점수 변경을 구분하고, 결론도 두 변경을 함께 명시 | 완료 |
| 외곽 폭 축척을 “단위만 정한다”고 설명한 부분 | 같은 상수로 환산하면 최근접 형상군의 순서는 유지되지만 30 mm 기준의 잔차 크기는 달라질 수 있다고 수정. 학습 자료의 상수로 바꿔도 판정이 같았다는 결과 유지 | 완료 |
| 공저자 판독의 자료와 판단 근거 | 작업대·레일을 포함한 대상 사진과 같은 카메라 상태의 전체 형상군 기준 사진을 비교하는 설명 유지 | 이미 완료된 사항으로 처리 |
| 판독 기준 사진의 정답 근거와 23건의 범위 | 기준 사진의 별도 실물 정답 근거가 없다는 한계와, 23/23이 전체 라벨 정확도의 추정치가 아니라는 설명 유지 | 이미 완료된 사항으로 처리 |
| 주장 범위 | 등록 형상군 정확도의 우월성이나 학습 검출기의 필수성을 단정하지 않고, 공정 내 운용 가치와 적용 한계를 유지 | 적절 |

Table 3의 짧은 방법명에는 간격 조건을 대표로 적었지만, 캡션에서 순서에 무관한 검증 점수를 함께 사용했다고 명확히 설명한다. 초록·본문·결론도 같은 내용을 전달하므로, 표현을 다시 바꾸도록 요구할 필요는 없다.

## 3. 새로 추가한 실험은 무엇을 보강했는가

v19는 개선된 템플릿 정합을 공통 미학습 조건에도 적용했다. 제외하는 형상군을 템플릿, 탐색 영역, 설정 선택, 축척 S의 산출에서 모두 제외했다고 보고한다.

| 평가 항목 | 제안한 학습 검출기와 CAD 목록 | 개선된 템플릿 정합과 CAD 목록 |
| --- | ---: | ---: |
| 등록 형상군 식별, 주 평가 | 361/361 | 356/361 |
| 형상군 제외 실험에서 미등록 도어 보류 | 361/361 | 323/361 |
| 제외한 형상군의 CAD 값을 등록한 뒤 식별 | 361/361 | 326/361 |
| E38 LH RR을 학습에서 제외한 뒤 CAD 등록으로 식별 | 29/29 | 0/29 |
| 대상 밖 E23의 CAD 값을 등록한 뒤 식별 | 6/6 | 0/6 |

템플릿 정합의 해당 결과는 시험 결과를 본 뒤 수행한 사후 진단이다. 주 평가와 구별하여 해석해야 한다.

### 3.1 알려진 형상군에서는 단순한 방법도 높은 성능을 낸다

개선된 템플릿 정합의 356/361은 기존 결과와 같다. 추가로 여섯 템플릿 설정을 각각 고정했을 때도 352~358개를 맞혔다고 보고하므로, 초기 190/361을 고전 기법 전반의 성능 한계로 해석하기 어렵다는 점이 더욱 분명해졌다.

원고는 이 사실을 인정하고 있다. 제안 방법의 가치를 초기 기준선과의 큰 정확도 차이에만 의존하지 않는 현재의 서술이 적절하다.

시간 분할 결과가 검증 점수 변경 뒤 133개에서 129개로 감소한 이유도, 검증 영상 3장에서의 작은 점수 차이가 다른 템플릿 크기를 선택하게 했다고 설명하였다. 검증 점수를 바꾸면 모든 평가에서 반드시 성능이 높아져야 하는 것은 아니므로, 이 변화 자체가 수치 모순은 아니다.

### 3.2 미등록 형상군에서는 현재 구현의 제약이 드러난다

넓은 E38 LH RR에서는 남은 형상군으로 정한 탐색 영역에 실제 모서리 홀이 충분히 포함되지 않았다. 원고는 해당 모서리 홀 주석 10점 중 2점만 영역에 들어 있었다고 보고한다.

작은 E23에서는 두 홀 사이의 간격이 약 390화소인데, 템플릿 정합에 적용한 최소 수평 간격이 500화소였다. 이 조건에서는 참값의 홀 쌍을 선택할 수 없으며, CAD 값만 추가해도 올바른 식별로 이어지지 않는다. 원고의 환산값인 500화소 약 581 mm를 사용하면 390화소는 약 453 mm이므로, CAD 거리 458 mm인 작은 도어에서 생긴 문제라는 설명과도 부합한다.

제안한 학습 검출기는 영상 전체에서 홀을 따로 검출하여, 이 템플릿 구현의 고정 탐색 영역과 최소 간격에 의한 제한을 직접 받지 않았다. 새 결과는 이 차이를 구체적으로 보여 준다.

### 3.3 어디까지 결론을 내릴 수 있는가

이 결과가 뒷받침하는 것은 **이번 템플릿 정합 구현에 둔 탐색 영역과 간격 조건이 형상군의 치수 범위를 제한했고, 제안 방법은 보고된 범위 밖 사례에서도 작동했다**는 점이다.

탐색 영역을 넓히거나 간격 조건을 다르게 설계한 모든 고전 기법까지 실패한다고 입증한 것은 아니다. 현재 원고는 실험 설정과 실패 원인을 직접 설명하고, 사후 진단임을 한계에 명시한다. 이 범위를 유지하면 충분하며, 여기서 다시 새로운 고전 기법 비교를 필수로 요구하지 않는다.

추가한 미등록 실험은 v18에서 선택적 보강으로 언급했던 사항이다. 이번 수행은 논문을 더 구체적으로 만들었지만, 앞으로도 비교 실험을 끝없이 확대해야 한다는 뜻은 아니다.

## 4. 수치와 서술의 일관성

새로 추가된 수치에 대해 다음 관계를 확인했다.

| 확인 항목 | 계산 또는 확인 결과 |
| --- | --- |
| 템플릿 정합의 CAD 등록 후 결과 | 정답 326 + 보류 3 + 오판 32 = 361 |
| 등록 도어 반복 판정 결과 | 정답 2,482 + 보류 8 + 오판 37 = 2,527 |
| 미등록 보류의 형상군별 집계 | E38 LH RR 3 + 나머지 형상군 320 = 323 |
| 제외 형상군의 도어 수 | E38 LH RR 29 + 나머지 332 = 361 |
| CAD 등록 후 정답의 형상군별 집계 | E38 LH RR 0 + 나머지 형상군 326 = 326 |
| 제안 방법과 템플릿 정합의 기존 등록 형상군 비교 | 361/361 대 356/361로 초록·표·본문·결론에서 유지 |
| 공저자 판독 문단 | v18의 상세 설명과 한계를 그대로 유지 |

보고된 합계와 구성 사이에서 새로운 산술 모순을 발견하지 못했다. 이 확인은 개별 실험 기록의 재현 검증을 대신하지 않는다.

## 5. 검토가 계속 반복되고 있는가

지금까지의 수정에는 실제 내용상의 진전이 있었다. 기준선의 축척 실패를 분리했고, 개선한 고전 기법의 높은 성능을 공개했으며, 공저자 판독의 실제 방식과 정답 근거의 한계를 정리했다. 따라서 같은 문장을 바꾸었다가 되돌리는 작업만 반복한 것은 아니다.

다만 검토가 길어질수록 필수 수정과 연구를 더 강하게 만드는 선택적 제안을 명확히 구별해야 한다. 이전 의견에서도 미등록 템플릿 정합 평가는 필수 조건이 아니었다. v18에서 최종적으로 남긴 필수 사항은 두 설명의 정확성이었고, v19는 둘 다 충족한다.

이제 기존에 인정한 단일 현장·후향 평가·소수 표본·실물 정답 근거의 한계를 다시 새로운 결격 사유로 삼거나, 추가 비교 방법을 계속 늘리는 것은 적절하지 않다. 현재의 연구 질문과 주장 범위를 기준으로 검토를 마무리할 수 있다.

## 6. 검토 종결 의견

논문의 핵심은 고정 지그 환경에서 공통 홀 검출과 CAD 목록을 분리한 구조를 실제 생산 자료로 평가하고, 판정 근거와 형상군 등록의 운용 특성을 설명한 데 있다. v19는 외관 CNN과 고전 기준선이 잘 작동하는 조건도 인정하면서, 미등록 형상군에서 발생하는 차이와 그 원인을 구체적으로 제시한다.

**이번 내용 검토에서 추가 필수 수정은 없으며, 필수 추가 실험도 없다. 현재 v19를 투고본으로 사용할 수 있다.**

이후에는 새로운 실험이나 표현 수정만을 목적으로 버전을 계속 늘리기보다, 실제 외부 심사에서 제기되는 구체적인 질문에 대응하는 것이 적절하다.
