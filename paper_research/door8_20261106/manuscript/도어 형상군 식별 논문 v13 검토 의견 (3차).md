# 도어 형상군 식별 논문 v13 검토 의견 (3차)

Nov 11, 2026 · @민수

v13 원고는 내용 기준으로 "게재 가(可)" 판정입니다. 실제 심사였다면 게재를 허용할 수준이라는 뜻이며, 새 실험이나 재학습이 필요한 지적은 없습니다. 다만 3.1절의 운용 판별기 서술이 4.3절 결과와 충돌하므로 투고 전에 원기록 확인이 필요합니다.

이 의견은 Claude가 엄격한 심사위원을 가정해 작성한 사전 검토입니다. 양식·편집 사항은 교신저자 요청에 따라 제외했습니다.

## 판정의 의미

"게재 가(可)"는 논문 심사 판정 등급 가운데 "게재 가능"을 뜻합니다. 추가 실험이나 재심 없이, 문장 수준의 수정만으로 실을 수 있다는 판정입니다.

세 차례 검토에서 판정은 다음과 같이 바뀌었습니다.

| 원고 | 판정 | 요지 |
| --- | --- | --- |
| v11 | 수정 후 재심 | CNN 비교군의 수치 결함, 데이터 선별 기준 불명확, 분량 14쪽 등 주요 지적 6건 |
| v12 | 수정 후 게재 | 주요 지적 6건 반영. 본문 내 모순 1건을 포함한 필수 수정 5건 |
| v13 | 게재 가 | 필수 수정 5건 반영. 아래 4건의 확인과 문장 수정만 남음 |

이 판정은 학회의 실제 심사 결과가 아닙니다. 실제 게재 여부는 편집이사회가 추천한 심사위원 2인의 의견과 학회 논문심사 규정으로 정해집니다([논문집필요강](https://www.ksmte.kr/sub/index.kin?main=4&sub=2) 18항). 배정되는 심사위원에 따라 추가 수정 요구가 나올 수 있습니다.

## 투고 전에 확인·수정할 것

오류이거나 본문 안에서 서로 맞지 않을 수 있는 항목은 4건입니다. 1번은 데이터 기술의 사실관계이므로 원기록 확인이 먼저입니다.

1. **3.1절 운용 판별기 서술과 4.3절의 충돌** (v13에서 새로 생긴 문제)
   - 3.1절은 운용 판별기가 9월 23\~24일까지 깊이 평면 방식이었고, 작업자 입력과 다른 세션이 11개뿐이며 나머지 361세션에서는 일치했다고 합니다.
   - 4.3절에서 깊이 평면 방식은 도어 361개 중 29개(8%)를 오분류(16개)하거나 보류(13개)했고, 검출기를 바꿔도 같은 경향이었다고 합니다.
   - 두 서술이 함께 성립하려면 설명이 필요합니다. 세션 판정이 교체 후 버전으로 전 기간을 다시 계산한 값인지, 아니면 실제 불일치가 11개보다 많았고 그중 11개만 입력 오류였는지 확인해야 합니다.
   - 확인 결과에 따라 3.1절에 재계산 사실을 한 문장으로 밝히거나 불일치 세션 수를 고칩니다.
2. **4.4절 E23 수치**
   - "측정 D 중앙값 454 mm, 가장 가까운 등록값과의 차 266 mm"는 서로 맞지 않습니다.
   - 724 − 454 = 270 mm이고, 266.5 mm는 Table 6에 적힌 최솟값입니다. "최소 266 mm"로 고치면 됩니다.
3. **CNN의 도어 단위 보류 규칙 미기재**
   - 3.3절에는 영상 단위 임계값만 있고, 도어 한 개를 언제 보류로 세는지가 없습니다.
   - 2.3절 규칙(판정된 영상의 최빈값, 전부 보류일 때만 도어 보류)을 CNN에도 썼다면 미등록 도어는 20장 중 1장만 수락되어도 수락으로 집계됩니다.
   - 같은 규칙이라면 등록 도어 보류 6\~9%는 그 도어의 영상이 전부 보류된 경우입니다. 영상 5% 임계값만으로는 설명되지 않으므로 등록 도어 결과는 오히려 강해집니다.
   - 2차 검토의 "이 수치의 상당 부분은 규칙의 결과"라는 지적은 도어 규칙을 확인하지 않은 추정이었고, 위 규칙이라면 틀린 지적입니다. 초록과 결론에 넣은 "95% 수락 임계값" 조건은 사실 서술이므로 그대로 두어도 됩니다.
4. **서론의 작업자 입력 오류율 분모**
   - 374세션에는 빈 지그와 설치 조정 촬영 2세션이 들어 있습니다.
   - 도어가 있던 372세션 기준이면 11개는 3.0%, 5개는 1.3%입니다.

## 검산 결과

원고 안의 수치를 다시 계산했고, 불일치는 위 2번(E23) 하나입니다. 원자료와 코드는 보지 않았으므로 수치가 실제 실험 결과와 같은지는 확인하지 못했습니다.

- 초록은 149단어로 상한(150단어) 이내입니다.
- Table 1의 판정 여유 8행과 합계(도어 361개, 영상 7,104장)가 일치합니다.
- Table 5의 도어 합계(361, 133)와 Table 6의 합계(74, 47, 53)가 일치합니다.
- Table 7과 본문의 범위(42\~55개, 33\~45건 = 6.4\~8.7%, 2.0\~3.2%, 5\~28개)가 일치합니다.
- Wilson 95% 구간 8개를 다시 계산했고 모두 일치합니다.
- 미등록 영상의 최소 거리 36.9 mm(세 시드)는 Table 6의 시드 42 최솟값 37.6 mm와 모순이 없습니다.
- 4.2절의 726.3 mm는 Table 6의 38.7 mm(765 − 726.3)와 일치합니다.
- 2차 검토의 필수 수정 5건은 모두 반영되었습니다.
