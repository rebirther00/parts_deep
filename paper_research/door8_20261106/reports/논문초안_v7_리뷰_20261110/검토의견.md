# 논문초안 v7 검토 의견

검토일: 2026-11-10. 대상은 v7 HWPX 정본, 동반 MD·DOCX·13쪽 PDF, 검토답변·작성확인사항·차별성 문서이다. v6 검토와의 차이를 확인하고, 새로 정정한 수치를 저장 특징에서 재계산했다. 원고 원본 7개와 실험 결과는 수정하지 않았다.

## 1. 판단

**v6의 C1~C4는 핵심 취지에 맞게 해결됐다. v7은 소규모 문구·기록·배치 교정을 마치고 투고를 진행할 수 있는 수준으로 판단한다. 이번 검토에서 추가 학습이나 새로운 실험을 투고의 필수 조건으로 요구할 근거는 발견하지 못했다.**

연구의 중심 주장이 명확하다. 공통 홀 검출과 CAD 판정 목록을 분리하고, 거리 표현별 실패를 판정 여유로 설명하며, 등록 목록 변경과 학습하지 않은 형상군에 대한 동작을 실제 생산 도어로 검증했다. CNN의 정확도보다 우월하다거나 임의의 미등록 품종을 거절한다는 주장을 하지 않는 현재 범위가 타당하다.

게재를 보장한다는 뜻은 아니다. 남는 심사 쟁점은 기존 구성요소를 결합한 방법이 생산 공정에 제공하는 실증 지식의 가치, 한 현장·한 시드의 범위, 소프트맥스 기준선에 한정된 비교이다. 현재 원고는 이 한계를 공개하고 있으며, 이전의 비교 조건 불일치나 U의 과도한 해석을 그대로 두고 투고하는 상태는 아니다. 제조·생산 응용 논문으로서의 기여를 중심으로 심사를 받는 것이 적절하다.

## 2. v6 지적과 저자 답변에 대한 판단

| 항목 | v7 확인 내용 | 판단 |
|---|---|---|
| C1 U 반례 | 5겹 7건·시간 분할 4건을 실물 8개의 평가로 구분. 9/6/5, 9/6/5, 9/8/3을 공개하고 최빈값 원리로 설명 | 해결 |
| C1 결론 | 픽셀 폭의 모든 측정 가능한 ‘시험’ 영상과 도어 U 최대 0.50을 나누어 서술 | 저자 수정이 맞음 |
| C2 scope | 기존 결과를 보존한 정정 기록, 역할별 함수 처리, 시험 호출부 3곳 수정 | 실질 해결. 로그 해시 설명만 아래 정정 |
| C3 마스킹 | 재정규화 수식, 제외 형상군을 뺀 검증 표본, 최소 약 95% 수락과 실제 수락률 명시 | 해결 |
| C4 분모·캡션 | 제외 형상군 합산 8장·48점, 같은 시험 주석 재사용, 반복 판정과 AUROC 정의를 4.4절로 이동 | 해결. PDF 배치만 최종 확인 |

**‘시험 영상’으로 한정한 저자 의견을 수용한다.** 이전 검토에서 내가 제안한 “측정 가능한 모든 영상”은 학습까지 포함하면 틀린 문장이다. 학습 쪽 초과 1건을 이전 검토에서 짚지 못했다. v7의 결론과 5.3절의 추가 공개가 더 정확하다. 이것은 시험 수치의 변경이나 새로운 누출 증거가 아니다.

**측정 가능한 영상에 한정한 ‘동치’ 논리도 원칙적으로 수용한다.** 기하 검사 등을 통과한 유효 측정값에서는 올바른 판정 영역의 내부와 외부를 최근접 CAD 및 30 mm 규칙으로 설명할 수 있다. 이 관계를 도어별 중앙값 U의 성공·실패와 혼동하지 않은 점도 적절하다. 다만 정확히 경계에 놓인 값까지 닫힌 구간으로 포함하면 동률 처리가 필요하다(아래 3.1).

**캡션 설명의 4.4절 이동과 비대칭 행 유지는 모두 수용한다.** 이전 검토는 이미 “주석 또는 4.4절”을 제안했고, 비대칭 조건 축소는 필수 변경이 아니라고 했다. 따라서 답변서의 이 두 항목은 실질적인 견해 차이가 아니라 허용된 편집 선택이다. “제안된 대안 중 4.4절을 택했다”, “참고 행을 유지했다”로 설명하면 더 간결하다. 비대칭 결과는 현재 표본에서 노출 여부에 따른 결과 변화를 확인하는 참고 근거로 유지할 수 있다.

## 3. 남은 교정

### 3.1 ‘동치’를 유지하면 경계 동률을 한 문장으로 처리

위치: 원고 3.2절의 구간 정의, `v7_검토답변.md` 2.1절, `v7_작성확인사항.md`의 동치 설명.

E25 LH FRT 724 mm와 E30 LH FRT 765 mm의 중간값은 744.5 mm다. 이 점은 양쪽 판정 여유를 모두 닫힌 구간으로 쓰면 두 형상군에 포함되지만, 구현의 최근접값 `argmin`은 CAD 목록에서 먼저 나오는 E25를 선택한다. 따라서 E30의 하단 경계까지 포함하여 “구간 안이면 항상 E30 정답”이라고 쓰면 정확하지 않다. ±30 mm의 보류 경계는 `>30`에서 보류하므로 그 경계 자체는 수락한다.

권장 문장:

> 측정 가능한 영상에서 구간 내부는 정답 판정에, 구간 외부는 오분류 또는 보류에 대응한다. 인접 CAD 값의 중간값에서는 목록 순서의 동률 규칙을 적용하며, CAD와 정확히 30 mm 차이인 값은 수락한다.

현재 본문의 “여유 밖이면 오분류 또는 보류”와 “U<1이면 중앙값이 구간 안”이라는 핵심 문장은 유지할 수 있다. 이번에 재계산한 픽셀·깊이의 학습·시험 측정에서 최근접 CAD 동률은 발견하지 못했다. 이는 수학적 끝점 설명을 정밀하게 하는 교정이며, 기존 수치나 U 정의를 다시 바꾸거나 재학습할 사유는 아니다.

### 3.2 정정 기록의 ‘로그 5개도 sha256 기록’은 실제 파일과 다름

위치: 답변서 2.2절, 작성확인사항 C2 행.

`errata_localization_scope_20261110.json`에는 산출물 14개 각각의 해시와 JSON 경로가 있다. 로그 5개는 경로 문자열만 있고 해시는 없다. 14개 산출물의 해시 및 16개 scope 경로를 모두 대조했으며, 로그 5개에도 해당 잘못된 문자열이 있음을 확인했다. 정정 범위는 맞다.

다음처럼 고치면 충분하다.

> 영향받은 JSON 산출물 14개의 sha256·JSON 경로와 관련 로그 5개의 경로를 기록하였다.

로그 해시까지 원한다면 새 정정 기록에 보충할 수 있다. 이번 검토의 `근거대조.json`에는 확인 당시의 로그 해시를 별도로 남겼다. 기존 결과를 덮어쓰지 않고 정정 기록을 연결한 처리 자체는 적절하다.

### 3.3 차별성 문서 질문 11에서 74개와 361개의 조건을 명시

현재 답변은 희소 형상군의 한계에 대해 “결론은 합계(74도어)와 5겹 결과(361도어)에 두었다”고 쓴다. 361개가 공통 미학습 조건의 반복 검증처럼 읽힐 수 있다. 본문은 이미 두 조건을 올바르게 구분하므로 문서의 이 답변만 정밀하게 쓰면 된다.

> 공통 미학습 비교는 폴드 0의 합계 74도어에 한정하며 형상군별 결과는 기술적으로 보고했다. 361도어의 5겹 결과는 공통 학습 조건의 목록 제거 및 일반 식별 평가 근거로서 별도로 제시했다.

같은 문서 주장 B의 “판정 여유 밖 영상 0”도 “시험 영상 0”으로 적으면 단서 열을 읽기 전에도 범위가 분명하다. 원고 5.3절 첫 문장의 “다섯 폴드의 계산 가능한 모든 영상” 역시 “모든 시험 영상”으로 맞추면 더 일관된다.

### 3.4 PDF 10쪽 Table 7의 배치

제공된 PDF에서 Table 7은 왼쪽 단 하단에 캡션·머리행·데이터 2행만 나오고 나머지가 오른쪽 단 상단으로 이어진다. 머리행은 반복되어 있고 내용은 읽히지만 핵심 비교표의 흐름이 끊긴다. 최종 편집에서 Table 7을 한 단 안에 배치하는 편이 좋다. Table 8은 오른쪽 단에서 이어 읽을 수 있고, 5쪽의 새 수식과 12쪽 결론은 확인한 범위에서 읽힌다.

HWPX의 본문·제목·캡션은 MD와 일치했고 라이브러리 구조 검증을 통과했다. 다만 제공 PDF는 LibreOffice가 DOCX에서 만든 근사본이다. 한컴오피스의 HWPX 실제 배치와 메모 화면을 본 것은 아니므로 최종 제출 PDF는 한글에서 다시 확인해야 한다. 저자·소속·교신저자와 후기의 사업명 자리표시자도 남아 있다.

## 4. 이번에 확인한 근거

새 추론이나 학습 없이 저장 검출점, 고정 분할, 학습 세션 보정값으로 두 거리 표현의 학습·시험 잔차를 재계산했다.

| 픽셀 폭 조건 | 학습: 판정 여유 밖 / 측정 가능 | 시험: 판정 여유 밖 / 측정 가능 |
|---|---:|---:|
| 5겹 합계 | 1 / 21,259 | 0 / 7,087 |
| 시간 분할 | 0 / 3,786 | 0 / 2,616 |

학습 초과 1건은 폴드 4의 `20260831/E38_door_LH_FRT/s_183313`, `58:rgb_0140.png`이다. CAD 812 mm에 측정 764.119 mm(잔차 −5.8967%)로 E30 LH FRT로 판정됐다. 해당 모델의 학습 역할 영상이며, 시험 영상 실패로 바꾸어 집계할 사례가 아니다. 이 도어가 다른 폴드의 시험 역할에 등장할 때에는 그 폴드의 모델로 평가한다.

깊이 방식의 U≥1이면서 도어 정답인 11건도 재현했다. 고유 실물은 8개이며, 과반 보류가 아닌 세 사례의 정답/오판/보류는 답변서와 같다. 여유 사용률을 성공 확률이나 미래 신뢰성 예측으로 확대하지 않는 현재 해석을 지지한다.

좌표 평가 함수는 실제 폴드 0 시험 주석 8장·48점에 대해 `role='val'`과 `role='test'`를 각각 전달하여 비교했다. 수치·점별 오차는 같고 scope만 바뀌었다. 세 시험 호출부가 `role='test'`를 전달하는 것도 확인했다. 과거 산출물의 잘못된 scope는 설명 메타데이터 문제였다는 판단이 유지된다.

v6와 v7의 MD 표 행은 모두 같았다. v6에서 이미 확인한 공통 학습 120개 평가와 엄격 제외 검출기 8개의 전체 감사는 반복하지 않았다. 이번 검토는 변경된 주장·정정 기록의 확인에 집중했다. HWPX는 상위 문단 121개·전체 문단 568개·표 객체 22개·그림 4개이고 초록은 공백 기준 150단어이다. 주요 수정이 MD에만 있고 HWPX에서 빠진 경우는 발견하지 못했다.

## 5. 투고 판단과 다음 작업

우선 할 일은 위의 작은 문구 교정, Table 7 배치, 저자·후기 정보 확정이다. 리뷰어 답변의 논거와 수치는 대체로 충분하며, 타당한 저자 반론을 다시 철회할 필요가 없다.

추가 보강을 선택한다면 공통 미학습 조건의 다른 폴드·시드 반복이 현재 가장 작은 실험 범위를 직접 넓힌다. 더 강한 미등록 검출 기준선은 CNN 전반과의 비교 주장을 확대하려 할 때 필요하다. 두 항목 모두 지금 투고를 무기한 미루게 하는 필수 조건으로 요구하지 않는다.

제출 시에는 현장 전이의 회복, 거리 표현에 따라 달라지는 실패, 미학습 형상군에서 공통 홀 검출과 CAD 판정이 유지된 관측을 기여로 제시하면 된다. “새 검출 아키텍처”, “모든 미등록 품종 거절”, “미래 실패율 보장”으로 표현을 확장하지 않는 것이 현재 근거와 맞는다.
