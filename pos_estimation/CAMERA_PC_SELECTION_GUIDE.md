## 1. 사용 시나리오

### 목적
- **부품 인식 (Classification)**: RGB 이미지로 부품 종류 분류
- **위치 추정 (6DoF Pose)**: RGB + Depth로 부품의 3D 위치/자세 추정

### 환경 구성

| 환경 | 용도 | 구성 |
|------|------|------|
| **랩 테스트** | 개발, 데이터 수집 테스트 | ZED 2i + 노트북 |
| **공장 설치** | 고정식 데이터 수집/추론 | ZED X Mini + ZED Box Mini |

## 2. 컴퓨팅 장비 비교

| 항목 | ZED Box Orin NX 16GB | ZED Box Mini (Orin NX 16GB) |

| **PoE 지원** | ✅ | ❌ |

## 4. 구매 옵션 가이드

### ZED 2i 옵션

#### 렌즈 FOV (2.1mm vs 4mm)

| 렌즈 | 수평 FOV | 수직 FOV | 2.5m 높이 촬영 범위 |
|------|---------|---------|-------------------|
| **2.1mm (광각)** | 84° | 54° | **4.5m × 2.5m** |
| **4mm (표준)** | 53° | 31° | **2.5m × 1.4m** |

> 💡 **1.5m × 1.5m 작업대를 2.5m 높이에서 촬영**: **2.1mm 광각** 필수
> (4mm는 수직 1.4m로 작업대가 프레임에 다 안 들어옴)

#### Polarizer (편광 필터)

| 환경 | 추천 |
|------|------|
| 금속 부품 촬영 (반사 많음) | ✅ **Polarizer 있음** (+$50) |
| 실외 촬영 | ✅ **Polarizer 있음** |
| 실내 + 무광 부품 | Polarizer 없음 |

#### USB-C Dual Screw

| 환경 | 추천 |
|------|------|
| 진동 있는 공장 | ✅ **Dual Screw** |
| 장기 고정 설치 | ✅ **Dual Screw** |
| 테스트/임시 사용 | 일반 USB-C |

### GMSL2 Fakra 케이블 (ZED X용)

| 길이 | 용도 |
|------|------|
| 0.3m | 카메라-Box 바로 옆 |
| 1.5m | 책상/소형 셋업 |
| **5m** | 일반 공장 설치 (권장) |
| 10m | 넓은 공장, 천장 설치 |

> ⚠️ 최대 케이블 길이: 15m

### ZED Box Mini 옵션

#### WiFi 6 (+$36)

| 항목 | 내용 |
|------|------|
| 모듈 | Intel AX210 |
| 주파수 | 2.4GHz / 5GHz 듀얼밴드 |
| 안테나 | 2x 외장 안테나 포함 |
| Bluetooth | ✅ 포함 |

> 💡 유선 이더넷 가능하면 WiFi 불필요 (유선이 더 안정적)

## 7. 기술 정보

### ZED SDK 호환성

**ZED 2i와 ZED X 시리즈는 동일한 ZED SDK 사용**

```python
import pyzed.sl as sl

# 카메라 초기화 (ZED 2i든 ZED X든 동일한 코드)
zed = sl.Camera()
init_params = sl.InitParameters()
init_params.depth_mode = sl.DEPTH_MODE.NEURAL

zed.open(init_params)

# Depth 가져오기
depth = sl.Mat()
zed.retrieve_measure(depth, sl.MEASURE.DEPTH)

zed.close()
```

> 💡 USB(ZED 2i) → GMSL2(ZED X) 전환 시 코드 수정 불필요

### ZED Box Mini OS

| 항목 | 내용 |
|------|------|
| **OS** | Ubuntu 22.04 기반 L4T (Linux for Tegra) |
| **JetPack** | JetPack 6.2 / L4T 36.4 |
| **아키텍처** | ARM64 (Jetson Orin) |
| **기본 계정** | ID: `user` / PW: `admin` |

**일반 Ubuntu와 차이점:**
- 사용자 경험은 거의 동일
- apt, Python 등 동일하게 사용
- x86 전용 프로그램은 ARM 버전으로 설치 필요
- CUDA/cuDNN/TensorRT 사전 설치됨

### ZED Box Mini 인터페이스

| 포트 | 수량 | 용도 |
|------|------|------|
| **HDMI 1.4** | 1개 | 모니터 연결 |
| **GMSL2** | 2개 | 카메라 연결 |
| **USB 3.0** | 1개 | 키보드/마우스 (허브 필수) |
| **이더넷 RJ45** | 1개 | 네트워크 |
| **DC 전원** | 1개 | 10.5~13.5V |
| **GPIO 10핀** | 1개 | CAN, UART 확장 |
