# 레이저 트래커 GT 측정 절차서 (도어 포즈 절대 정확도 검증)

목적: `T_cam→door` 6DoF 추정의 **절대 정확도**를 레이저 트래커 실측으로 확인한다.
합격 기준: **±5mm / ±1°** (지표 체계의 3축 — 정합·반복은 상시 평가, 절대는 본 측정으로 완성).

검증은 두 방법을 병행한다. **방법 1은 등록(registration)이 필요 없어 실패 위험이 없고**,
방법 2는 전 포즈 데이터로 트래커↔카메라 변환을 최적 추정한 뒤 잔차를 본다.

- 방법 1 (필수, 등록 불필요): 포즈 i→j **변화량** 비교. 도어를 옮긴 양을 트래커와 카메라가
  각각 재고 ΔT를 직접 대조한다. 스케일 오차(예: 과거 ×0.85 압축 같은 문제)가 그대로 드러난다.
- 방법 2 (권장): 전 포즈 쌍으로 `X = T_cam←trk` 최적 추정 후 포즈별 잔차. 포즈에 따라 변하는
  오차(거리·기울기 의존 편향)가 드러난다. 포즈 공통 상수 편향은 X에 흡수되므로 하한 추정이다.
- 방법 3 (선택): 독립 기준점 3+개(트래커 프로브 + 카메라 식별 겸용)로 X를 별도 등록하면
  상수 편향까지 완전한 절대 검증이 된다.

## 1. 준비물

- [ ] 레이저 트래커 + SMR(리플렉터), 홀 측정 수단: **핀 네스트**(홀 삽입형) 또는 터치 프로브
- [ ] 도어 1종 이상 (권장: E25_door_RH 등 현장 평가 이력이 있는 클래스) + 대차/지그
- [ ] 도어 고정 클램프 (측정 중 도어가 1mm도 움직이면 안 됨 — 대차 바퀴 브레이크 포함)
- [ ] 현장 카메라 시스템 정상 동작 (door-capture 웹 UI http://localhost:5000)
- [ ] 본 저장소 `pos_estimation/pos_pipeline/tracker_template.json` 사본 (기록 양식)
- [ ] (방법 3 시) SMR 네스트 3개 + 네스트 중심을 카메라로 식별할 마커

## 2. 사전 준비 (측정일 이전)

- [ ] `python 05_evaluate_tracker_gt.py --selftest` 실행 → PASS 확인 (분석 파이프라인 검증)
- [ ] 트래커 소프트웨어에서 점 좌표를 mm 단위로 내보내는 방법 확인
- [ ] 포즈 계획 확정 (아래 3절) — 최소 6포즈, 권장 8포즈

## 3. 포즈 계획 (권장 8포즈)

카메라 시야 안에서 6홀(볼트 4 + 코너 2)이 모두 보이는 조건으로:

| 포즈 | 거리(대략) | 자세 |
|---|---|---|
| P1, P2 | 1.3m | 정면 / 정면(좌우로 ~150mm 이동) |
| P3, P4 | 1.5m | 정면 / 좌우 기울임 ~10° |
| P5, P6 | 1.5m | 상하 기울임 ~10° / 면내 회전 ~10° |
| P7, P8 | 1.7m | 정면 / 임의 복합 |

## 4. 당일 절차 (포즈당 반복)

1. 도어를 계획 포즈로 옮기고 **완전 고정** (클램프 + 브레이크)
2. **트래커: 6홀 중심 측정** (아래 5절 방법) → 포즈 ID와 함께 기록
3. **카메라: 세션 촬영** — 웹 UI에서 해당 클래스 선택 후 정상 세션 1회(20프레임).
   세션 폴더명(`s_HHMMSS`)을 포즈 ID와 함께 기록
4. **드리프트 체크**: 트래커로 홀 1개 재측정 → 처음 값과 차이 ≤ 0.3mm 확인.
   초과 시 해당 포즈 폐기 후 재측정
5. 기록 양식에 즉시 기입 (포즈 ID / 6홀 좌표 / 세션 폴더 / 재측정 차이)

주의: 2와 3 사이에 도어·대차·카메라 어느 것도 건드리지 않는다. 사람이 카메라 시야를
가리지 않은 상태에서 세션을 촬영한다.

## 5. 홀 중심 측정 방법

랜드마크 6홀 = 래치 볼트홀 4(각공 모서리) + 상단 코너 프레임 홀 2. 목표는
**홀이 뚫린 표면상의 홀 중심** 좌표다.

- 핀 네스트 사용 시: 핀을 홀에 삽입, SMR 안착 → 측정값은 홀 축 위 표면에서 일정
  오프셋 위 점. 같은 네스트를 6홀 모두 동일하게 사용하면 오프셋이 홀 축 방향으로 일정
  → 표면 법선 방향 오프셋은 방법 1(변화량)에는 영향 없고, 방법 2 잔차에서 z 상수로
  일부 흡수된다. 오프셋 값(핀 네스트 규격)을 기록해두면 스크립트에서 보정 가능
- 터치 프로브 사용 시: 홀 원주 4점 이상 + 주변 표면 3점 → 소프트웨어의 원 피팅으로
  표면상 중심 산출 (트래커 SW 기능 사용)

정밀도 목표: 홀당 0.5mm 이내. 스크립트가 6홀↔CAD 강체 정합 잔차를 출력하므로
(정상 ≤ 1mm) 측정 품질을 현장에서 즉시 확인할 수 있다.

## 6. (선택) 방법 3 기준점

SMR 네스트 3개를 카메라 시야 내 고정 구조물에 부착 → 트래커로 네스트 중심 측정 +
카메라로 같은 점 식별(마커 중심 px + depth). 6절 입력 파일의 `reference_targets`에 기입.

## 7. 데이터 입력 및 실행

`tracker_template.json`을 복사해 측정값 기입 후:

```bash
python 05_evaluate_tracker_gt.py --input tracker_20260905.json
```

출력: 방법 1 변화량 오차 표(포즈 쌍별 Δ병진 mm / Δ회전 °), 방법 2 포즈별 잔차,
트래커 프로브 정합 잔차, 합격 판정. `artifacts/eval_tracker_gt_*.json` 저장.

## 8. 판정

| 항목 | 기준 |
|---|---|
| 트래커 6홀↔CAD 정합 잔차 | ≤ 1mm (측정 품질 게이트, 2mm 초과 시 해당 포즈 재검) |
| 방법 1 변화량: 병진 오차 med | ≤ 5mm (p95 ≤ 7mm) |
| 방법 1 변화량: 회전 오차 med | ≤ 1° |
| 방법 2 잔차: 병진/회전 med | ≤ 5mm / ≤ 1° |

방법 1이 합격이면 스케일·회전 정확도가 실물로 입증된 것이고, 방법 2까지 합격이면
포즈 의존 편향도 예산 내라는 뜻이다. 방법 3 수행 시 상수 편향 포함 완전 절대 검증.
