- (9/9) **공통 평가 집합 확정**(datasets_eval20): 8/27~9/7 유효 세션, 세션당 최대 20장, 세션 3개 이상 8종 83세션 1,571장. 홀 판별기·CNN·자세 추정을 동일 집합에서 평가. 2026 KSAE 추계 학술대회 초록 v3 작성("현장 데이터 수집·검증 체계 구축 사례").

## [노트 2] 2026-09-16 ~ 09-23 — 전체 재평가·드리프트 감시, CNN 정식 폴백 교체(블라인드 검증), 픽셀 폭 기준 측정 전환, 품번 14종·레이더 옵션 판정 확장, 연차보고서 초안

**2. 수행 내용**
- (9/16) 홀 판별기에 **미등록 도어(unknown) 판정** 추가(최근접 CAD D와 30mm 초과 시 억지 배정 금지). 실시간 서버(18)에 CNN 폴백 통합(보류 프레임만 CNN 투표, 홀 판정 우선, 불일치 표시).
- (9/16) 잔차 스케일 K를 현장 83세션으로 재적합(1.0140→1.0064): |D−CAD| p95 18.3→11.8mm, 판정 변경 0. 세션별 드리프트 지표(K_session·dev·z·tilt)를 DB(session_hole_metrics)와 웹 대시보드 /drift에 기록·시각화. 대시보드에 최신 벤치마크 카드 추가.

- (9/23) 9/16 오후~9/23 유입 **35세션 663장 블라인드 평가**(어떤 학습·분할에도 미사용): 홀 판별기 663/663, CNN seed916 99.4% vs run #10 84.3%(E30 뒷문 12/60, E25 앞문 0/20). run #10은 학습 중 val loss 폭발 후 덜 학습된 체크포인트가 저장된 run으로 진단 → **seed916을 정식 폴백으로 교체**(LFS 배포 모델 갱신). 학습 불안정 원인(역빈도 클래스 가중치 최대 23배 + lr 1e-3)에 대해 클래스 가중치 기본을 sqrt 역빈도로 변경, 5-fold 재검증 착수.
- (9/23) K 드리프트 원인 분석: 세션별 K·z/cos(tilt)가 0.16%로 일정 → 도어 위치·픽셀 폭은 불변이고 **깊이 맵 자체가 세션마다 ±1.4% 스케일·겉보기 기울기 5~11°로 흔들리는 아티팩트**로 판명. 운영 규칙 4안 오프라인 비교(186세션 |dev| p95: 상수 K 15.1 / 이동 중앙값 14.9 / z 앵커 9.7 / **픽셀 폭 5.2mm**) → 홀 거리 D를 **픽셀 폭 × 상수(S_PIXEL)/fx** 로 측정하고 깊이는 z·tilt 가드로만 쓰는 방식 구현·전량 검증(185세션 3,762프레임 판정 변경 0, |dev| p95 15.1→4.1mm, 경보 10→0, 최소 마진 12→17mm) 후 기본값 전환.
- (9/23) 통합모델 SIDE DOOR 어셈블리 도면 14종·사양표 입수·분석: 품번 14종 = 형상군 9종 × RADAR 옵션(LH REAR·RH). 기존 RR/RH CAD 5종이 RADAR 사양이고 현장 라벨 안에 두 사양이 혼재함을 확인(코너 홀·볼트 사각은 공용 → D 판정·자세 불변). 학습 없는 규칙 검사(6점 좌표계로 CAD 브래킷 홀 2개 투영, 밝기 + 깊이 판 높이)로 RR/RH 148세션 자동 판정 → 사용자 크롭 검토·확정 147세션(레이더 52·없음 95), 품번 정확도 고정 test 596장 100%.
