##### ◦ 부품 위치 추정 알고리즘 개발을 위한 모사 시험 환경 구축

부품 위치 추정은 실측 정답(GT) 자세를 현장에서 직접 얻기 어려우므로, 정답이 알려진 모사 환경과 실물 환경을 병행하여 구축함.

- ㅇ CAD 기반 합성 모사 환경: 도어 CAD(STL, 8종)를 정답 자세로 z-버퍼 렌더링하여 깊이 영상(도어 뒤 400mm 배경 평면 포함)을 생성하고, CAD 홀 좌표를 투영한 뒤 랜드마크 픽셀 노이즈·깊이 노이즈를 주입하는 환경(04_evaluate_synthetic.py)을 구축함. 검출기를 우회하고 기하 체인(평면 피팅 → 리세스 보정 역투영 → 볼트 대응 → 강체 정합)만을 GT와 직접 비교할 수 있음.
  - 조건 3종: clean(노이즈 0), field(랜드마크 1px + 깊이 3mm — 현장 유사), stress(2px + 6mm). 8종 × 6포즈 = 48회, 카메라 내부 파라미터는 현장 실측값 사용.
- ㅇ 실험실 실물 환경(1차년도 계승): 세종 실험실의 도어 8종 실물 RGB-D 1,256장(ZED X Mini)에 홀 랜드마크 라벨을 추가하여 홀 검출기 학습·홀드아웃 평가에 사용함.
- ㅇ 현장 지그 환경: 명성공업 용접 지그 상부에 카메라를 고정 설치하여 도어가 지그에 장착된 실제 조건(거리 약 1.45m, 정면)에서 데이터를 수집함(상세는 "학습 데이터 수집 장치 설치" 절).
- ㅇ 절대 정확도 실측 환경(준비 완료): 레이저 트래커로 도어 6홀 중심을 측정하여 카메라 추정 자세와 대조하는 절차서(8포즈 계획, 홀 측정법, 판정 기준 ±5mm/±1°)와 기록 양식·비교 스크립트(05_evaluate_tracker_gt.py, 자체 검증 통과)를 준비함. 【장비·일정 확보 후 실측 예정】

**표 2 부품 위치 추정용 기초 데이터셋 구성**

| 구분 | 내용 | 규모 | 용도 |
|---|---|---|---|
| 홀 랜드마크 라벨 | 래치 볼트홀 4점 + 모서리 프레임 홀 2점(힌지·래치)의 픽셀 좌표를 자체 제작 브라우저 라벨링 도구(15_label_holes.py)로 수작업 표기 | 134장 × 6점(실험실 118 + 첫 방문 현장 16), 학습 107 / 홀드아웃 27 | 홀 검출 CNN 학습·평가(판별·자세 공용) |

- ㅇ 전처리·규약: 카메라 좌표계는 OpenCV 광학 좌표계(x우/y하/z전방, mm)로 통일하고, 세션 meta.json에 좌안 rectified 내부 파라미터(fx=fy=1269.746, cx=961.669, cy=598.594, 시리얼 54910212)를 기록하여 저장 영상 평가와 실시간 추론이 같은 역투영 경로를 쓰도록 함. 근사 내부 파라미터(fx=1065) 경로의 절대 거리가 0.85배 압축되어 있던 문제를 실측값 적용으로 해소함.
- ㅇ CAD 정합 시 관측면(카메라가 보는 면)은 CAD 설명 문서의 ±Z 규약을 정본으로 하고 STL 좌표(Z=−Y)로 매핑함. 코너 홀에는 평행이동 쌍둥이 홀(30~74mm 간격)이 있어 검출 6점의 상대 배치 특징(ul, wl, uh, wh, D)으로 판별함.
- ㅇ 연속 프레임(2초 간격)은 중복이 크므로 학습·평가에는 세션당 최대 20장을 시간축 균등 선별하고, 분할은 세션 단위로만 허용함(자세 평가 집합은 판별기·CNN과 동일).

##### ◦ 평가 프로토콜: 세션 단위 분할과 공통 평가 집합

- ㅇ 한 세션의 연속 프레임은 동일 부품을 거의 같은 조건으로 촬영한 것이므로 프레임 단위로 학습/시험을 나누면 성능이 과대평가됨. 따라서 분할은 세션 단위(70/15/15)로만 허용하고, DB의 auto-split이 기종별 세션을 시간순으로 배정함(세션 3개 미만 기종은 전부 train, 클래스별 첫 확보 세션은 test로 고정). 프레임 단위 분할은 금지함(그림 9).
- ㅇ 외관 기반 CNN은 단일 분할 수치가 test 세션 1개로 ±8% 흔들리므로, 세션을 5개 묶음으로 나눠 모든 세션이 한 번씩 시험되는 세션 그룹 5-fold 교차검증으로 대표 수치를 산출함.
- ㅇ 공통 평가 집합(2026-09-09 확정, datasets_eval20): 8/27~9/7 유효 세션 전부, 세션당 최대 20장 → 세션 3개 이상인 8종 83세션 1,571장(별도: E25_door_LH_FRT 1세션 20장). 홀 판별기·CNN·자세 추정을 같은 집합에서 평가하여 학회 초록 v3·내부 보고 수치의 정본으로 삼음.
- ㅇ 최신 평가(2026-09-16·09-23): 9/16 유입분까지 반영한 유효 151세션을 재분할(train 103 / val 23 / test 25세션 596장)하여 test를 재평가하고, 9/16 오후~9/23 유입 35세션 663장은 어떤 학습·분할에도 쓰지 않은 블라인드 집합으로 별도 평가함.
- ㅇ 실험실 데이터의 지위: 실험실 8종 1,256장은 1차년도 프레임 단위 층화 분할을 유지하고 현장 평가와 분리함. 오프라인 증강 세트는 학습 금지·강건성 평가 전용이며, 현장 성능은 현장 세션 격리 기준으로만 공표함.

##### ◦ 접근 방식 전환: 형상 학습 CNN에서 설계 치수 기반 기하 판별로

- ㅇ 1차년도 실험실 모델(RGBD/RGBE ResNet18)은 실험실 시험셋 99.5~100%였으나, 현장 개체에 그대로 적용하면 14.1%(2026-04 현장 78장)·22.9%(현장 384장, 세션 격리)로 붕괴함. 도어 8종은 형상이 거의 같고 치수(폭 828~1,456mm, FRT 계열 최소 차이 41mm)만 다른데, 클래스당 실물 1개로 학습한 CNN이 개체의 외관을 암기한 결과임.
- ㅇ 이에 AI는 "홀 위치 검출"에만 쓰고 판정은 설명 가능한 CAD 치수 비교로 하는 홀 랜드마크 기하 판별기를 주 판별기로 확정(2026-08-26)하고, 외관 기반 CNN은 현장 데이터로 재학습하여 홀이 가려지거나 프레임 밖일 때의 보조(폴백) 판별기로 운용함(2026-09-07 결정).
- ㅇ 중간 단계로 검토한 CAD 설계 속성 기반 파이프라인(MobileSAM 전경 분리 → 정면 뷰 변환 → 통풍구 U-Net → CAD 템플릿 정합 × 종횡비)은 실험실 99.2%·현장 그룹 100%였으나 기종 판별에서 홀 판별기 대비 이점이 없어(그룹 제약 기여 +0.5%p) 2026-09-11 폐기·아카이빙하고, 폴백 역할은 CNN이 승계함.

### 3-1. 정성적 연구개발성과

- ㅇ 현장 데이터 확보 체계: 작업자 버튼 조작만으로 세션 단위 RGB-D 데이터가 자동 저장·업로드·DB 등록되는 무인 수집 체계를 구축하여 4주 만에 9종 192세션 18,303쌍의 실제 생산 현장 데이터를 확보함. 이는 1차년도 실험실 데이터(1,256장) 대비 규모와 조건 면에서 현장 적용 검증의 기반이 됨.
- ㅇ 설명 가능한 부품 판별: 형상을 학습하는 CNN 대신 CAD 치수(모서리 홀 간 거리)로 판정하는 기하 판별기를 개발하여, 실험실 위주 134장의 홀 라벨만으로 현장 9종에서 판정 정확도 99.9~100%를 달성함. 신규 기종은 CAD 치수 등록만으로 재학습 없이 추가되며(E23 사례), 판정 근거(D, 마진, 게이트)가 사람에게 설명됨.
- ㅇ 품번 단위 판정: 도면·사양표 분석으로 어셈블리 품번 14종 체계를 정립하고, 형상군(홀 거리 규칙) × 레이더 옵션(브래킷 투영 규칙 또는 4채널 검출기)의 2단 구조로 품번을 판정함. 학습 없는 규칙 검사와 사용자 확정으로 하루 만에 147세션의 옵션 라벨을 확보하였고, 블라인드 35세션 663장에서 규칙·4채널 검출기 모두 품번 정확도 100%를 확인하여 실시간 서버에 품번 출력을 통합함.
- ㅇ 데이터 신뢰도 관리: 판별기가 라벨 검증 도구를 겸하는 세션 단위 검증 루프로 작업자 오선택 4세션과 미등록 기종 6세션을 발견·정정하였고, 촬영 프로토콜 이전 세션 제외 기준과 세션 단위 분할·교차검증·블라인드 평가라는 현장 성능을 과장하지 않는 평가 기준을 확립함.
- ㅇ 위치(자세) 추정 기반 확보: 자세 라벨 없이 홀 검출 + 깊이 평면 역투영 + CAD 강체 정합으로 6자유도 자세를 산출하는 비학습 기하 파이프라인을 구현하고, 합성 GT로 기하 체인의 절대 오차(면내 0.8mm·법선 1.4mm·회전 0.35°)를 입증함. 현장 정합 잔차 중앙값 4.6mm로 2차년도 목표(10mm)를 자체 평가 기준으로 충족함.
- ㅇ 운영 인프라: 메타데이터 DB·웹 대시보드·드리프트 감시·모델 배포 동기화 등 데이터 유입에서 평가·감시까지의 운영 절차를 스크립트화하여, 이후 세션이 쌓일 때마다 같은 절차로 재평가할 수 있게 함. 깊이 스케일의 계단식 변화(9/9 이후 약 0.7%)를 드리프트 감시로 조기 발견하고, 원인을 깊이 맵 아티팩트로 규명하여 판정 거리를 픽셀 폭 기준으로 전환함(세션 간 D 편차 p95 15→4mm, 판정 변경 0).
